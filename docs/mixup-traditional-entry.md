# Mixup：定位底模、真实块组合、旋转与填色

正式入口为 `MixupInputScreen`，覆盖八款 Mixup / Mixup Plus。三阶外壳帮助定位；求解使用实际几何、真实块型、连接关系和颜色。

## 操作

- 点选棱位、内棱位或中心位，直接列出当前位置可用的真实块组合，例如两棱、棱＋两中心、四中心等。卡片每张实际面片只画一次；跨两侧观察的同一中心面合为一张图，棱块的两张不同面沿真实接缝连在一起，并注明实际物理块型及数量。组合使用同一视角和遮挡顺序，整体缩小每个实体块来留出块间隙，不再把同一面并排投影两遍或分别缩小棱块两面。
- 定位底模的中心位、棱位不限定原始块型：中心可以进入棱位，棱也可以进入中心位。面片的块型及连接关系来自所选组合或真实打乱，不根据底模位置推断。
- Plus的中心／棱组合直接以同型号普通Mixup的菜单为参照，沿用其组合、顺序、朝向与操作流程；按对应原始网格块和同一刚体姿态，替换成Plus自身的真实面片。333都是2类，334都是5类，344都是7类，444都是3类；不再另建Plus局部菜单并集。单面／两侧仅表示从哪里观察，不决定它来自哪种实体块。
- 同一个组合的整体旋转方向合并为一张卡片。普通位置左右箭头每次转90°；内棱每次转180°。这是修改录入草稿，不是模拟拧层。内棱以两个黑色面交会的长棱定位；旋转轴通过棱段中心、沿其到魔方原点的径向，半转保持整条棱段的位置，两个端点交换。彩色面随完整块体换到不同平面，不再绕彩色面中心旋转。
- Plus 333的内棱只有整块一种组成；Plus 334／344提供整块、同向、反向A、反向B四类；Plus 444提供同向、反向A、反向B三类。两种反向分别翻转其中一个楔块，不能靠整组旋转180°互相代替。相对方向与整体方向分开，翻转会带动完整斜切块体，菜单顺序固定。对称反向组合整体转180°时块身可以重合，但两张色面及其颜色会交换实际位置。
- 内棱卡片使用真实楔形块体的立体图，不再用相同的矩形配不同箭头来表示方向。主模型也读取录入的完整块体，显示实际三角侧面和斜面；没有实体块体信息的定位格才使用通用封闭占位块。
- 两块反向内棱的黑色长棱共线，但彩色面不共面。卡片以长棱为锚点，并使用正反朝向共同的固定视口，旋转时不自动重新居中。按固定棱段保存颜色，即使彩色面改了平面也不会丢色；同一长棱上的小块不再按各自色面中心拆到不同录入位置。
- 配色栏与组合菜单同时显示。初始点模型只选中；点一种颜色开启连续上色，再连续点面片即可使用该色，不会吸取面片原来的颜色。切换画笔颜色时只改变画笔，不会误改上一张面片。再次点选中的色块退出上色，可继续只选块调整组合和方向。未选择组成的位置仍先选组成，再点实际面片上色；每次实际改色可撤销。
- 同一个中心面投影到棱的两个侧面时，视为同一张物理面片，填色自动同步。棱块的不同彩色面分别填色。
- 不再进入形状图库，也没有核对形状、核对方向、逐块确认的步骤。选择组合已经确定实际面片的形状和朝向。
- 软件打乱和拧动返回的状态直接沿用原来的真实几何，点击即可选中改色。按整个实体块的彩色表面确定所属位置；同一棱块的两张面一起归属当前组合，避免把45°棱块的一张面误分给旁边的中心位。更换一个位置的组合时，未变化的面片保留颜色；同色共面的细分或合并也保留颜色，旋转后仍能明确对应的同型面也保留颜色。把不同颜色合成一张面时原子拒绝，提示先统一或清除这些颜色，不再直接丢色。旋转时颜色、连接及内棱楔形一起旋转；当前组合以外的位置不随之移动、清空或改色。新放置的面与邻块重叠时整次编辑保留原状，完整块数量和可达性仍在录完后校验。改组成、改方向、填色、清除均可撤销。
- 打乱状态与手动修改始终使用同一套几何绘制和点选编号，不再在第一次修改后切换显示路径。新组合尚未填色的部分显示为封闭、可点选的灰色块身，不会因缺色只剩薄面或侧壁消失。
- 普通位置本次编辑首次选中时保留其完整组合，常规表之外的形状单列“原组合”。内棱不额外显示“原组合”，按标准组合及180°方向识别当前形状。普通位置切换其他组合后卡片仍保留，可以切回原先的形状、方向和颜色；切到其他位置再回来也保留。点击已经选中的原组合不覆盖后续填色。新打乱、应用匹配状态或清空全部录入后重新建立这些参考选项。参考选项只在当前编辑页内保留，未作为持久会话字段保存。
- 组合名称的绘制与卡片图形分开，重绘和尺寸变化不会再清掉“原组合”“中心×1”“棱×1”等名称。
- 再次点打乱直接生成新状态，不要求先匹配未应用的录入。后台先生成完整的魔方和录入草稿，成功后才一起替换当前状态，支持撤销；失败或主动取消保留原有形状、方向与颜色。
- 换组合、撤销和打乱后清除旧的点选轮廓，防止重绘前的触摸误用旧的小块编号。
- 上方只保留一个“清除…”入口，点开选择“只清除选中面片的颜色”或“清除当前位置的组合和颜色”；前者保留形状，后者重置整个当前位置（棱位包含两侧）。底部垃圾桶仍清空全部录入。

## 真实组合表

- `cube/mixup_assembly.py` 使用对应型号的实际刚性块和姿态目录，按整个棱位或中心位建立局部组合。不是把一个长方形任意切成几格，再为格子随意指定块型。
- 一个组合的各物理块需完整覆盖该位置；用实际面片检查接触、相交和覆盖。普通四阶棱位的四块组合只保留四中心，三块组合只保留一棱加两中心。334／344 的中心存在不同尺寸，按实际几何列出能成立的全中心等组合。
- 同一块的两张彩色面在组合里属于同一物理块；同一中心面跨两个观察时只保存一种颜色，统计时只计算一次。
- 组合分组使用整组的真实旋转等价关系，不再仅用正方体的24种方向归组，包含错层对角线上的90°朝向；不能把两个组件分别旋转后当作同一个组合。内棱额外保留楔形本体和斜切方向，防止外部色面相同却丢失内棱方向。
- 组合随程序保存到 `assets/mixup_assemblies.json`，由 `tools/build_mixup_assemblies.py` 从模型生成。带版本和几何指纹；模型变化或表不存在时才重新计算。手机选择菜单无需反复扫描形状目录。
- Plus的中心／棱组合使用普通Mixup的实际组合目录为参照。按块型与原始父网格坐标找到Plus对应实体块，使用相同姿态取得其真实彩色面；不拉伸普通面片、不重新指定物理块型。重复的整体方向归到同一张卡片，旋转、连续填色、两侧联动沿用同一录入页。
- 组合资源版本9包含普通系列参照菜单，以及固定长棱的两种反向内棱。所有24个内棱观察位置、四款Plus共648个组件记录的完整面片与块体，均在现有实际姿态目录中找到对应几何。

## 状态、渲染与求解

- `cube/mixup_entry.py` 的版本8草稿保存真实面片、原始块型、内部楔形几何、组合来源及录入方向。对能与旧模板及已记录半转完全对应的版本7内棱，迁移为固定长棱的几何并按棱段保留颜色；真实导入姿态和不能识别的旧形状不猜测转换。同线内棱重新归组，几何修正后需重新匹配。版本1—6的整块面片归组迁移仍保留，旧版已经删除的信息无法补回。
- 输入页不再把四分小面同时当成中心、棱或角。组合确定块型，填色只改变颜色；切换组合或旋转会改变录入几何。
- `cube/articulated_observation.py` 的匹配器同时约束颜色、完整三维面片、原始块型和内棱楔形方向。满足唯一匹配后才应用可拧动状态，求解器读取实际模型；不会为了通过校验而把中心换成其他块型或丢掉内棱方向。
- 已知打乱状态保留实际三维形状，修改颜色不重建成三阶方格。内棱方向在录入、打乱展示和匹配中一致。
- 完整回转后按物理块比对已知状态：内棱180°两次、中心／棱90°四次，若块型、跨面连接、全部面片颜色和内棱块体方向完全恢复，继续使用原可拧动模型及其打乱历史；不重新匹配并丢失恢复形状所需的路径。重开旧草稿后点应用／还原也会进行这项比对。缺失信息、实际改色或几何改变仍走正常匹配，录入方向标签和观察辅助线不参与物理状态判断。
- 组合菜单列出当前模型定义下的局部结构；录入旋转允许表达尚未校验的朝向。点应用后检查实际面片、块数量、跨面颜色和连接；不匹配、信息不足或超时都保留草稿。结构匹配成功后，可达性及求解仍由对应求解器判断，有限搜索超时不代表已经证明无解。允许输入四个方向不等于保证四个方向都能组成可解状态。
- 旧版“绕彩色面中心翻转”生成了姿态目录外的块体；版本8草稿／版本9组合表改用固定长棱的真实几何，不再沿用该错误模板。逐组件有真实姿态对应不等于任意局部组合都能组成可达状态，完整录入仍需校验数量、碰撞、连接与求解可达性；本轮未验证全部实物状态的还原。

## 打乱失败与超时处理

- 首次45°转动形成合法错层时立即保存候选，不再等待后续跨轴外层转动成功才保存。后续加深耗尽预算时返回已有候选；没有合法错层候选时仍报失败。三阶普通／Plus继续要求中心和棱双向互换。
- 相同形状丰富度的候选优先保留操作更深的颜色打乱，避免初始一两步候选一直覆盖后续结果。短打乱仍明确提示深度较浅。
- 刚性姿态索引和直角姿态集合共享缓存；克隆复用同状态的不可变几何数据。切层检查缓存实际彩色面顶点的轴向范围，上限8192条，仍检查原来的每条边界，没有放宽角度、整块切层或角块姿态限制。
- 开始打乱时停止尚在计算的组合菜单任务；生成成功后才记录撤销快照，失败与取消不添加空撤销步骤。

局部编辑、界面回调、历史恢复和无打乱历史的匹配检查见 `tests/test_mixup_entry_edits.py`、`tests/test_mixup_input_screen.py`。手机触摸、完整实物覆盖及全部求解情况仍需另行验证；未生成 APK。
