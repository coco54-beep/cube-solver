# 转面八面体求解修复

用户截图：二阶求解报 `Polyhedral reduction replay failed`。

原因：二阶的模型有六个四贴片角块以及两组各四个单色面块。原核心求解仅选角块，后续约简又只选大于六块的轨道，导致八个单色面块从未参与求解。四阶也有同类小轨道遗漏。

修复：

- 核心点集统一纳入角块和不超过六块的小轨道。
- 二阶核心覆盖全部 14 块、32 个贴片。
- 将二至四阶核心的稳定子算法预先生成并随应用打包；当前压缩数据为 2,724 字节。
- 数据记录几何指纹，不匹配时按修复后的完整核心重新构建。
- 运行时仍通过独立状态回放确认整体复原，再显示解法。
- 内部求解失败不再使用“请检查录入”作为弹窗标题。

本次生成了状态无关的算法数据，未运行打乱求解测试，未重新打包 APK。
