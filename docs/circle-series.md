# Circle / Crazy Planet 系列

## 入口

首页「圆圈魔方系列」，采用现有的型号选择框，包含 Circle 2×2 与 Crazy 3×3 Plus 八大行星。原特殊异形列表中的 Circle 2×2 入口已移入本系列。

## 二阶模型

采用圣手 Circular 2×2 的固定角结构：圈外8个角块，圈内24个面片，
圈内面片按隐藏棱的两端成对联动；总共48个可独立取色的面片。
初始固定角位于 D/L/B（黄／橙／蓝），三条相邻面为跟转面。
固定角移动后，机构参考方向随之更新，而不是永久绑定三个世界坐标面。
转包含固定角的一层，也会带动相应的内圈；其它层按隐藏棱的切层移动。

`Circle2Cube` 保存颜色和固定角位置。录入、随机打乱、撤销、拧动、
回放进度跳转、会话恢复都保留这两部分状态。旧版普通二阶上画圆弧的
实现已移除，旧装饰模型的存档不再作为真实圆圈状态载入。

二阶求解会检查全部48个面片和固定角位置；不能只完成外层就报告还原。
软件打乱及连续拧动支持经过完整回放确认的逆序还原；无有效操作依据的
手动状态采用包含机构方向的双向短搜索，最多覆盖六步。复杂实物状态
的完整手动求解尚未实现。桌面预览位于 `artifacts/circle2/`，本次未打包 APK。

## 三阶模型

每面 17 个独立可取色区域：8 个圈外面片、8 个圈内扇区、1 个中心，总计 102 个。外层角、棱保持跨面联动；圈内扇区按本面规则选择是否转动。圆弧采用统一的分段几何边界，录入、拧动、回放使用同一套置换。

- 0 面：转动该面时，本面圈内不动；相邻面的受影响扇区仍按该层移动。
- 1 面：本面圈内跟随该面转动。
- 转角为 90°；面标识 `3:0` 表示第 3 面的圆圈规则是 0。

以下为软件采用的标准拿法，使用 U/R/F/D/L/B 面名，不能据此假定所有厂家的贴纸方向完全一致。

| 型号 | 跟转圆圈（1 面） |
|---|---|
| 水星 | U |
| 金星 | U、D |
| 地球 | U、R |
| 火星 | U、R、L |
| 木星 | 除 U 外的五面 |
| 土星 | R、F、L、B |
| 天王星 | F、D、L、B |
| 海王星 | D、L、B |

## 当前求解范围

软件打乱及连续拧动保留可回放的操作依据，完整匹配当前 102 个色块后才能用于求解。改变任一录入颜色不会把失效操作依据当作正确解法。操作依据随会话保存和校验。

没有有效操作依据的手动录入只进行有时间和内存上限的双向短搜索，最多覆盖六步状态。超出范围明确提示暂不支持，不能把搜索未找到判成不可解。颜色检查按钮只确认数量正确，不能确认完整可解性。复杂手动状态的完整自动还原与公式教程尚未实现。
