# 三阶移棱魔方（Fisher Cube）

入口：异形魔方 → 特殊异形 → 移棱魔方。

- 三阶内部机制，26 个独立刚体块，立方体外壳绕竖直转轴偏转 45°。
- 上下中心是正方形；四个侧面中心跨两个颜色，四个中层棱块只有一个外部颜色。
- 使用形状与颜色卡片录入，支持自定义六色、恢复默认、随机打乱、清空与撤销。
- 点击块保持镜头，箭头切换观察视角；独立拧动页按内部转轴选层。
- 对单色中层棱的不可见翻转，选择外部几何完全相同且满足三阶约束的虚拟方向。
- 求解从录入状态开始，处理四个侧面中心朝向，再检查最终外形；上下方正方形中心可吸收不可见的旋转。
- 复用现有横竖屏求解和播放界面。

结构参考：[永骏移棱三阶产品](https://www.yjcube.com/heteromorphism/fisher-stickerless)，[David Guo 的变形魔方结构与特殊情况说明](https://www.davidguo.idv.tw/Cube/Heart.htm)。
