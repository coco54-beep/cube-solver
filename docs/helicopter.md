# 直升飞机魔方

入口：首页 → 转棱系列 → 六面体·直升飞机。

## 支持的结构

标准直切 Helicopter Cube：12条棱轴，每次180°，8个三色角块、24个单色三角中心块，共48个贴纸。中心分为四个六块轨道。模型、输入、拖动转棱、播放和教程共用同一套几何置换。

本版本支持仅使用常规半转打乱的状态，不支持斜转变形（jumbling），包括斜转后虽然恢复立方体、但中心轨道已经改变的状态。输入提示已注明，求解表会拒绝不符合常规转动约束的录入。

结构参考：[Jaap's Helicopter Cube / Curvy Copter](https://www.jaapsch.net/puzzles/helicopter.htm)。本型号没有 Curvy Copter 的十二个可见棱中心块。

## 求解与数据

先使用预生成表还原角块，再处理四组中心之间的奇偶性，最后通过独立三循环还原各组中心。每次返回解法前，均从实际录入的颜色重新完整回放；不依赖打乱历史。

离线生成：`python tools/build_helicopter.py`。数据位于 `solver/data/helicopter.bin`，带几何指纹，适用于桌面和 Android；手机无需重新生成表。

教程提供四组中心三循环的正反向典型情况，共八例。
