# 原创课程、旁白与视频导出

扩展目录的 32 个型号均有一个完整的固定实例课程。实例由独立打乱状态的求解结果生成，并在保存及打开时用对应型号的模型逐步回放验证。它们与原有的机构练习、局部公式练习分开显示，不依靠现场重新搜索才能打开。

课程共保留 10,954 个动作；最长的 Master Brilic 实例为 2,456 步。每段最多 64 步，“上一段／下一段”可以跳转；分段不删减动作。讲解包含机构参照、握法、工作区提示及本段完成后的可观察目标。章节是这一实例的播放区间，不表示每一段都对应一个通用的人类还原公式。核对其他实物时仍需进入录入求解。

在演示页打开“旁白”，会先讲解本段，再继续动画。暂停、换案例、返回或应用切入后台会停止旁白，旧回调不能重新启动播放。中文原创课程使用系统的中文语音；没有对应系统语音时会明确提示，不会把无声播放冒充带旁白播放。

“导出视频”支持完整案例及当前段，可选择是否包含旁白。输出为 480×640、12 帧／秒的 MP4，保留真实转层动画、章节文字及动作进度，并附带独立的 SRT 字幕。长解导出耗时较长，可随时取消。导出使用独立模型，最多排队三张画面，不会改变录入状态，也不会一次保存全部画面到内存。

Windows 使用系统语音及可用的 FFmpeg；找不到编码器时会提示。Android 使用系统 TTS 和原生 H.264/AAC 编码，完成后可通过手机的文件选择器另存，无需额外存储权限。临时文件在任务结束或取消后清理。

验证记录见 `reports/course-audit/2026-10-25/`。Android 编码和混音已在 API 33 模拟器运行；该模拟器没有系统语音引擎，手机上的系统语音与文件保存还需要真机联测。本次只修改和检查源码，没有重新打包发布。

## 播放、加载和时间估算

播放速度可选 0.5、1、1.5、2、3 倍；调整速度时回到上一完整动作再继续，避免半步状态污染模型。“章节 i/总数”可打开目录并跳到对应起点。当前动作说明固定显示在播放按钮上方，对应真实的面、层、方向和角度；特殊机构沿用模型的实际转轴标记。章节旁白加入本段开始的三个实际动作，不凭空为任意长解分段编造通用公式阶段。

已校验的课程模板最多缓存两个，打开时返回独立模型和独立章节文字；编辑或播放某个实例不会污染模板。长课的有界检查点仍保留全部动作。

导出选择页给出按当前动作速度估算的视频长度，旁白时间为估算值。实际导出开始后，先测量设备处理速度，至少完成三个动作且运行一秒后才显示预计剩余处理时间；编码阶段单独提示。两种时间含义不同，均不承诺精确完成时刻。速度不加快系统旁白，保证讲解仍可听清。

Mixup 与 Tangram 等刚体模型增加最多四份、合计最多四万步的完整状态解法缓存，每份最多两万步。缓存仅复用相同模型基底、相同完整块位朝向的成功解法，并在存入和读取时分别合法回放核验；没有缓存时继续原求解流程。这减少重复求解，并不保证首次深层状态都能迅速完成。


## 转层提示与逐步讲解（2026-10-25）

黄色轮廓标出实际转层，青色线显示实际转轴和转向，跟随模型及镜头变化。公式沿用实际动画分解后的层和角度，连体模型采用相应核心的轴心。静止画面复用提示图形，离开页面或切入后台会停止更新；恢复应用仍保持暂停。

旁白按钮依次切换关闭、章节讲解、逐步讲解。逐步模式先讲当前动作，再启动该动作；暂停、换章节或切屏后，旧语音回调不能启动动画。视频导出采用章节旁白，带同样的转层和动作提示。
