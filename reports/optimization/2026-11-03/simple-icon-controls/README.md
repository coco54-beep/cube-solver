# 简洁模式只保留必要图标，删除“更多”

2026-11-03。尚未重新打包 APK。

## 修复

- 公共 `EntryActionRow` 的简洁操作栏只保留拧动、打乱、清空、撤销、求解；按型号实际支持的动作显示。
- 纯拧动型号使用拧动、打乱、撤销、重置模型、求解，不提供清空录入。
- 删除“更多”按钮、弹窗和附带三点图标资源。额外工具不会藏进菜单，而是在高级模式直接显示。
- 简洁策略由模式决定，横屏或窗口变宽时也不会自动显示全部工具。
- 普通 N 阶输入保持图标；批量填色、重做、公式输入、配色等辅助操作不显示在简洁操作栏。切到高级模式可恢复，配色设置仍为齿轮。
- Mixup 的清除当前块、上色／组合模式保持图标，刷新后不会重新叠上文字。
- 统一求解取消、失败定位／重试／继续修改，以及异形确认的操作图标。颜色、数字、方向及模式选择需要的信息标识保留。
- 此前仅把“更多”改成图标仍不符合用户要求，本次已完整移除。未引入运行时依赖。
