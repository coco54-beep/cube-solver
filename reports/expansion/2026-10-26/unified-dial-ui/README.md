# 魔豆、时间机器的基本界面统一

按用户要求，以现有魔方的基本布局和操作方式为准；型号特有的设置用按钮打开，不再单独占据一块常驻面板。

- 时间机器按用户最新选择，在颜色下方直接显示两排数字：1～6、7～12，每排六个。不再打开数字选择窗，数字高亮、自动递增和撤销继续生效；离开录入页后的旧按钮不能修改状态。
- 公共动作栏跟随全局简洁／常规模式。常规模式显示拧动、打乱、清空、撤销、还原态、还原六个图标，与现有异形魔方使用同一组件；不再仅因窄屏而强制变成文字和“更多”。简洁模式的主要按钮顺序也在各录入页保持一致。设置切换后立即更新已构建的动作栏。
- 普通魔方和多面体共用拧动页顶栏，统一返回与确认按钮的尺寸。回放使用公共播放／暂停按钮；长标题在自身区域内显示，避免压住按钮。
- 修复自定义配色在求解预览和回放页恢复默认的问题，时间机器 78 个显示颜色值、十面魔豆 10 色均正确传递。
- 录入失败、状态非法、超时、异常和取消都使用现有的行内反馈与恢复操作。补全时间机器／魔豆错误信息的本地化和问题位置；定位时同步真实观察面与朝向。失败不跳入播放页，不清空输入。
- “重试”对应失败的操作：打乱失败重试打乱，求解失败重试求解。取消、返回后控件恢复，旧任务的迟到回调不能跳页。
