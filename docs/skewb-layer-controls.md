# 三、五、七阶斜转的可转区域

本文仅针对斜转系列的三、五、七阶。恐龙二阶及其高阶格子四、六阶在目录和模型中独立分类，使用八个角轴，不属于本页的斜转切层定义。

七阶入口当前对应 Elite/Professor Skewb 的切割定义：沿体对角线有
`-.38、0、.38` 三道切面。三道切面分为四个可转区域，而不是七层。
五阶 Master Skewb 的两道切面 `-.275、.275` 分为三个区域。

此前几何生成器只从转轴正端依次生成区域，最后一道切面背后的
另一侧外层未加入可选转层。保留一个生成集可用于抽象求解，但
在直接拧动界面会造成一侧外层无法拖转的问题。

现已补入三、五、七阶的另一侧外层。三阶每条体对角线的两侧半块均可直接拧动。块的切线、贴纸数量和形状不变，
模型动画、拖动候选、随机打乱和求解生成元均从同一套精确置换读取。
旧层编号保持不变，新区域加在末尾；七阶菜单显示：

1. 前侧外层
2. 中间片 1
3. 中间片 2
4. 另一侧外层

五阶显示前侧外层、中间片 1、另一侧外层。转角仍为 120 度。
这里说的是直接可操作的区域，不将四个区域当作排除整体旋转后
的四个独立自由度。

资料：

- [cubing.js 的谜题切割定义](https://github.com/cubing/cubing.js/blob/main/src/cubing/puzzle-geometry/pgPuzzles.ts)
  中的 master skewb、professor skewb。
- [TwistyPuzzles 的机构设计讨论](https://twistypuzzles.com/forum/viewtopic.php?p=222566)：
  中央切面及两侧偏移切面、两个侧层和两个中间片的说明。

检查覆盖恐龙二阶、格子四／六阶、斜转三／五／七阶共 84 个直接转层：贴纸置换为双射，块集合旋转封闭，转动后逆转及连续三次转动均恢复原状态。三阶斜转新增的四个另一侧外层分别单步打乱后求解，四例均以一步还原。
尚未进行高阶随机求解回归和手机拖动实测；这些检查确认直接转层及置换，不等于穷举独立自由度与全部可达状态。
DaYan Seven/Compy Skewb 有独立尖角，是另一套机构，不能直接套用
本入口的 Elite Skewb 切割与自由度。
