# 拧动和还原播放时的镜头跟随

还原界面在“停留”下面增加统一的“镜头跟随”滑块，拧动界面及首页设置也使用同一个控件。所有魔方共用一个设置，包括五魔方和足球魔方；在任何页面调整都会同步到其他页面，并保存到下次启动。

滑块最左侧为关闭，向右为 30–360°/秒，每档 30°/秒。保留已有开关和速率偏好，首次使用默认 180°/秒。速率控制视角调整速度，独立于转层动画速度。跟随期间调整速率立即生效；关闭时镜头停在当前位置，继续执行待播放的转层。

普通魔方、多面体异形（包括五魔方、恐龙／格子和斜转），以及粽子、镜面和三阶变形魔方的拧动页共用跟随逻辑。正反转、拖动、撤销和重做均经过同一条转动动画路径。

还原播放也使用相同开关和速率，覆盖普通魔方、粽子、镜面、三阶变形、多面体异形、镜面魔塔及 SQ1。下一步、反向播放上一步、连续播放都会先观察实际转层，再执行转动；当前步完成后再计算停留时间。上一步的普通立方体机构使用反向动画。跳到起点、终点或拖动进度条仍直接跳转，不逐步跟随；跳转、返回或离开会取消等待中的镜头回调。

- 根据实际要转动的块集合定位观察方向；普通立方体机构使用所选层的位置。
- 当前转层朝向镜头、能看清时保持原视角；背面或难以看清时，先沿较短方位角路径转动镜头，再开始拧动。
- 调整镜头期间阻止新的拧动和手势，跟随滑块仍可使用；离开页面取消跟随回调。
- 镜头调整只改变观察角度，不改动块、颜色或录入草稿。无明确观察侧的中央切片保留现有视角。
- 高贴纸数量模型降低跟随动画的更新频率。

恐龙／格子拧动页默认选择镜头可见的角端，转轴菜单标出相邻面号；拖动后同步转轴和层选择，按钮继续操作刚才拖动的层。

本次未运行回归测试或进行手机实测。教学演示暂未接入自动跟随。
