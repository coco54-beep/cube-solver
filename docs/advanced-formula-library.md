# 进阶公式库和公式练习

首页左上角进入公式库。公式库离线提供 2–5 阶普通魔方、SQ1、斜转、金字塔和三阶五魔方的情况、公式及原生模型演示。目录支持公式集切换、编号/分组/公式搜索、分页和备选公式。

数据参考 [SpeedCubeDB](https://www.speedcubedb.com/)，保留情况编号、功能性转动公式和来源链接。模型、演示界面、拿法提示、阶段前提和练习计时由本项目实现；未复制原站的图片、视频、社区资料或教程正文。

截至 2026-10-16，目录由 221 个有公式的源页面合并成 43 个公式集，提供 6,060 个情况。

“可演示/练习”表示通过本地模型校验；练习入口按需求仅开放二阶、三阶、SQ1 和金字塔。

每个情况先从还原状态施加对应公式的逆操作，形成可观察的具体例题，再回放原公式确认完成。除此之外，对顶层类情况检查前两层是否保留，检查 PLL 顶色、金字塔 L3E 底层、斜转第一层和相邻角块侧色，以及五魔方后续各层。SQ1 每次斜切必须满足切口合法性。逆公式回放本身不能证明公式的阶段名称正确，所以阶段检查单独执行。

公式用标准速拧记法：三阶宽层包括外层和中层，M/E/S 与标准方向一致；来源中的 `2R` 是第二片，`Rw` 是外两片。公式演示使用独立的标准记法模型和对应动画参数。金字塔大写转动同时带动尖角及主体，小写只转尖角。斜转使用来源的 Rubikskewb 角转记法和 S/H 宏；整转会实际旋转整个模型。五魔方个别公式开头未定义角度的 `x'` 拿法已体现在起始模型中，演示文字明确说明。

目录仅提供通过校验的公式，不保留待核对条目。导入时应用维护规则，确保更新数据后仍使用已确认的公式。

## Practice

公式库右上角进入练习，支持二阶、三阶、SQ1、金字塔。可多选公式集，从通过校验的情况中随机出题；同一轮题袋用完前不重复。题目先隐藏编号和答案，可旋转模型观察。打乱公式直接显示在计时器上方，选择公式集或切换题目时自动更新，无需打开弹窗；从还原状态执行该公式即可摆出当前题目。

出题会随机选择合法备选公式（设置常用公式后固定使用常用版本），并变化对位和拿法。答案包含恢复对位的准备动作，演示直接使用当前题目的模型与动作，不重新加载另一道例题。二阶、三阶、SQ1 在后台尝试用独立求解生成打乱，回放与当前模型完全一致才采用；计时在生成结束后可用。搜索超时、取消或没有找到可用方案时使用该题的合法逆向构造。金字塔目前使用备选公式及拿法变化，尚未采用独立搜索生成打乱。

公式库每个情况可以切换“未学／学习中／熟练”；备选公式列表可设置常用版本。学习进度和常用公式保存在本地偏好中，并与练习界面共享。练习可筛选全部、未学、学习中、薄弱优先、常用公式。薄弱模式包含尚未熟练的情况以及近期表现较差的情况，按最近用时、DNF 和学习状态调整出题顺序；仍保持同一轮题袋不重复。

计时使用单调时钟。手机点击开始/停止；桌面松开空格开始、按下空格停止，长按不会重复触发。完成用时记录在用户偏好中，最快和平均成绩按当前魔方及所选公式集统计。计时由使用者手动停止，不自动判断实物是否完成。

当前成绩可标记 OK、+2 或 DNF；ao5、ao12 各去掉一个最好和最差成绩后计算，一个 DNF 作为最差成绩去掉，两个及以上 DNF 则该平均为 DNF。单次最快和普通平均仅统计有效成绩，并计入 +2；完成题数包含 DNF。最近成绩列表显示当前魔方及所选公式集的最近 50 次，记录总量保留最近 500 次。

计时前或计时中查看答案的题目标记为辅助练习，不计入成绩；正常停止后查看答案保留已记录成绩。可以进入公式演示并返回原题，或开始下一题。离开页面时中止尚未完成的计时，不记为完成。

## 维护与校验

### 自动还原中的公式收尾

三阶、三阶五魔方和 SQ1 的求解器会将原解与公式库中的收尾方案比较。只有当前局面精确匹配、原生模型完整回放还原成功、且总步数更少时才替换。三阶的宽层、切片及换握转换为固定拿法的普通面转；五魔方按真实旋转对称性匹配不同拿法；SQ1 对齐上下层并在回放时检查每次斜切是否合法。没有匹配或用完追加计算时间时保留原解。不会将教学模型专用动作传入还原播放器。

公式索引预生成并离线打包，手机无需首次构建。索引缺失时仍使用原有求解器。四、五阶降阶过程中调用三阶求解器的部分也能使用该收尾优化；这不表示所有魔方、所有局面都会减少步数。

1. `python scripts/import_formula_library.py` 更新来源数据；下载缓存位于被 Git 忽略的 `tmp/formula-source/`。
2. `python scripts/validate_formula_library.py` 校验全部情况、选出符合模型及阶段要求的备选公式，并更新原生求解器的公式索引。也可用 `python scripts/build_formula_finishes.py` 单独重建索引。
3. `python -m pytest tests/test_formula_library.py tests/test_notation.py -q` 检查标准动作恒等式、动画方向、阶段前提和练习计时行为。
4. `python -m pytest tests/test_formula_finishes.py -q` 检查公式索引的全部原生回放、拿法转换和收尾替换。

Android 的 JSON 打包规则包含公式数据，Windows 打包清单也包含 `demo/data/`。本次未生成新 APK，也未通过 ADB 操作手机。
