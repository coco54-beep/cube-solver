# 移动端进度、取色校准与资源管理

## 自动保存与恢复

- 约每 5 秒保存一次，切到后台和正常退出时补写检查点。文件在应用私有数据目录，使用临时文件和原子替换。
- 保存当前魔方类型、阶数、录入颜色／块、当前页面、拍照各面结果与手动修正、还原序列和当前位置。
- 恢复还原页时保持暂停；计算中的任务不自动重跑，回到原录入页。
- 拧动页保留逻辑块状态；中断的普通魔方还原动作从上一个完整步骤恢复。照片会转存为最长边不超过 1280 的本地 RGB 数组，以继续调整取景框。
- 检查点使用受限类型的 JSON，不保存或执行 Python 对象代码。损坏或不兼容的文件记录日志并回退。
- 公式练习题、练习计时和撤销历史尚不属于此检查点的恢复范围。

## 校准持久化

- 普通魔方六色校准按 cube 保存；异形按模型类型保存，相同类型不同阶数共用颜色参考。
- 校准写入独立偏好键，不覆盖主题、语言、镜头设置或模型原配色。
- “恢复默认”清除该类型的拍照校准，并重新分类已有色样；手动改色保留。

## 内存与识别反馈

- 安卓不再在应用启动或刚进入五阶时预热大型求解资源，实际请求求解时加载。
- 各面保留小量 RGB／HSV 色样，用于后续重新校准；不再为每一面缓存整张照片。当前原图在拍摄页面前台仍可用于取色，切到后台时转存并释放。
- 进度条表示当前定位／取色／更新各面阶段，不表示预计剩余时间。可取消识别，忽略旧任务结果。
- 小模型以橙色边框标出当前面不确定色块。定位失败与取消保留照片及已有录入，手动改色不会被重新分类覆盖。
