# 优化第 2—6 项

只修改源码和验证，未打包、安装或发布。测试去重汇总见 `summary.json`。

## 改动

- **续算**：完整搜索保留实际搜索栈、候选游标、去重状态、当前阈值和累计耗时。接入 Mixup 完整物理搜索、Tangram Extreme 回形和长方体完整后备搜索。Mixup 还保留快速阶段已合法执行的前缀；取消后进入接续路线时不重跑快速阶段。新旧线程交接可取消，不共享活动搜索栈。求解页显示实际耗时和搜索量。
- **修正录入**：普通魔方逐次维护颜色计数，只有发生变化的块重新检查重复色、相对色；擦除或撤销会清除已经修正的局部提示。局部提示不代替最终的完整合法性校验。Mixup 缺失及邻块冲突带具体位置，冲突编辑仍原子拒绝，不丢掉邻块。
- **随机验证工具**：新增 `tools/audit_random_input_matrix.py`，可指定型号、种子、步数和单次评估时间。适配 39 个型号，包含八种 Mixup、两种 Tangram、迷彩、六种绑块、普通二至五阶及新增固定面多面体。只跨越序列化的可见录入数据边界，不给求解器原始姿态或打乱历史；Mixup 从空白菜单组合、实际旋转步长及颜色重建。它是数据层录入测试，另有真实界面操作测试。
- **教学**：黄色线标出实际转动层，青色线显示实际转轴与转向。普通公式直接使用动画分解后的轴和层，特殊机构使用物理层；连体魔方使用各自核心的真实轴心。旁白按钮按“关闭→章节讲解→逐步讲解→关闭”切换，逐步模式讲完当前动作再启动动画，旧旁白回调不能启动下一步。导出仍采用章节旁白，含相同动作提示。静止画面不重复重绘提示线。
- **资源**：启动不再自动导入普通两阶段／四阶求解表。四阶 51,482,970 字节距离表改为共享只读文件映射，最多缓存两个路径，避免整表读取后再复制。Windows 分发额外排除旧演示 GIF 与开发文档，Android 排除开发文档；源码快照也不再复制已退役的表和这些开发文件。有效离线表全部保留。

## 验证结果

- `final-regression.xml`：244 项通过。
- `real-input.xml`：204 项通过、4 项不适用跳过，包括实际 Mixup 录入控件、迷彩六视图和 Tangram Extreme 录入。
- `lifecycle-final.xml`：44 项通过，补充续算交接、逐步讲解、后台恢复和连体轴心检查。
- 三组按测试名称去重：**463 项通过，4 项跳过**。跳过的是普通 Mixup 没有可编辑内棱的四个参数，Plus 内棱仍在测试内。
- 两组新随机种子 `20261028` 和 `20261029`，分别 3 步／6 步：**39 型号 × 2 = 78 例全部合法回放还原**。记录位于 `random-matrix/`、`random-matrix-deeper/`；不代表所有目录型号或任意深度均已验证。
- 用真实 Mixup 搜索前沿在生产求解服务中触发取消，确认断点存在；重试显示接续，跳过旧快速阶段，并合法回放到还原态。另测回调更换、生成候选中途取消、限时暂停、改输入隔离、有界存储及旧线程交接。
- 实际页面导航：横竖屏 29×2=58 页，0 错误，记录仍位于 `reports/reliability-audit/2026-10-25/visible-pages/summary.json`。32 个新增型号的实际教学页控件检查全部通过，记录 `expanded-ui.log`。手机尺寸的五个录入／恢复／章节场景亦通过，见 `visible-final.log`。
- 实际 I-Cube 24 步带旁白、2 倍速导出成功，所有动作终态与独立回放一致、用户输入不变，12 帧复用／重绘对比通过。视频约 71.833 秒，音画长度相差不足一毫秒；`video-action.png` 已检查提示线和动作文字一致。
- `resources.json`：实际 51.48 MB 表映射只产生约 12 KB 的 Python 堆峰值（只测映射创建和抽样，不代表整个求解器的总内存或操作系统驻留页）。`assets.json` 检查全部活动离线表仍被包含，旧八表继续排除；额外开发资源约 2.4 MB。最终安装包缩减量需重新构建后测量。

## 边界

断点仅在当前运行期间保留，最多两个问题；尚未接入所有求解器，退出应用不保留计算现场。用户录入的保存与恢复沿用原有机制。随机矩阵未覆盖整个目录全部型号，更深、更广的种子可以用同一工具继续扩展。

检查在 Windows 桌面源码完成。安卓真机性能、系统语音、文件另存以及实体机械结构的全面认证不在本轮证明范围内。

QA 工具关闭 Kivy 的共享文件日志，将输出保存在本报告目录，避免多个测试进程同时清理用户日志时发生竞态；产品的正常日志不受影响。
