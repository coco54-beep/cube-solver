# 拍照录入支持与边界

更新：2026-10-25。

## 分类与入口

拍照菜单从现有魔方目录筛选支持型号，沿用目录的分类、顺序和型号名称，不维护另一套分类。普通魔方仍支持二至五阶；异形名单从 18 个型号增加到 44 个型号，合计 65 个型号与阶数组合。

新增名单包括普通 Tangram、四款五边形棱柱、三款固定形长方体，以及部分可按固定表面逐面填色的四面体、八面体、十二面体、二十面体和花瓣系列。完整名单见 `reports/camera-audit/2026-10-25/supported-models.json`。

需另外录入形状、组成、尺寸或方向的型号继续采用原录入方式，包括 Mixup、Tangram Extreme、彭罗斯、镜面、Blanker 和迷彩。仅有颜色无法可靠表达这些型号的实物状态。

## 录入与数据保留

逐面拍摄或导入图片，对齐外轮廓后识别；必要时可调整取色轮廓和校准颜色。可以只拍部分面，随后进入该型号原录入页修正或继续填色，未拍的位置保持未录入。

普通 Tangram 的识别结果保存为逐面颜色观察，再由原录入流程匹配实物状态；不把识别颜色写入内部的块姿态编号。固定形长方体按模型实际可见贴片取色，同一贴片对应的内部格子同步赋色。

返回拍照页时同步录入页的修改；没有修改的旧录入数据不会覆盖尚未应用的新照片结果。保存和恢复会保留识别数据、录入基准及面朝向。

## 本次验证

- 目录筛选、颜色数量、长方体贴片映射、部分录入、返回修改和会话恢复均有回归测试。
- 透视、模糊、亮度变化和颜色校准使用生成图片验证。
- 四个浅层随机状态完成全部面图片识别、构建无打乱历史的输入、实际求解和逐步回放校验：五边形棱柱、Dogic I、3×3×2、普通 Tangram。
- 桌面实际界面完成四项流程检查，包括导入图片、识别、打开原录入页和返回保留修改。

这些结果不等于已验证手机实拍准确率，也不保证任意深度状态均可求解。本次没有连接安卓实体相机测试，没有生成安装包。
