# 现有形变机构与实物依据筛查

日期：2026-11-02。本轮只检查和记录，没有改 App 分类、转动规则、输入入口或求解表，也没有打包。

后续更新：普通直升机、Rua、四叶草和紫荆花的补充见 [整块混转实现报告](../edge-jumbling/README.md)；十四面直升机、星寻足球和 AJ 四阶的进一步证据及限制见 [三型号核实报告](../three-model-verification/README.md)。下文保留首次筛查时的状态，不作为后续完成情况。

## 范围与判断方法

读取当前目录快照的 235 个型号／阶数入口，再重点核查容易漏掉混转的固定槽位实现。运行 7 款固定槽位模型各 100 步常规打乱、5 款刚体模型部分转角与逆转，并对 7 款立方机构换壳模型逐轴逐层检查四分之一转后的外壳。

“外形特殊”“模型带选形状输入”“能转动内部圆盘”都不能单独证明是形变魔方。固定槽位程序可以正确演示常规转动，却无法表示突出块及随形变改变的阻挡关系；其配色求解成功不证明实物全部动作已实现。

`mechanisms.json` 保存实际参数、参考文件路径、检查结果和限制。pCubes 文件只读取 XML，未执行任何嵌入脚本。

## 明确存在混转能力遗漏

| 型号 | 软件现状 | 实物／参考依据 | 结论 |
| --- | --- | --- | --- |
| 普通直升机 `helicopter` | `PolyhedralPuzzle` 固定槽位，仅 180°闭合动作；100 步后世界面片不变 | 本地 Helicopter cube.xml 有 JumbleAngle；实物档案说明约71°准备可使另一条棱转动，并记录隐藏棱 | 明确漏掉混转、形变及隐藏材料随之改变的阻挡 |
| Rua `rua` | `lanlan_polyhedra.specification` 为12轴180°；固定槽位 | 本地 Rua.xml 明确 JumbleAngle=acos(1/3)；Rua 实物档案说明允许 jumbling | 明确漏掉混转形变，不能把当前常规模式当完整机构 |
| 紫荆花 `mf8_bauhinia_minx` | `rex_dodecahedron.py` 明确仅120°固定槽位，不表示部分转角和隐藏填充 | 本地 Bauhinia.xml 明确 JumbleAngle；同名、同别名 Rex Dodecahedron，Inventor Mr. Fok | 混转缺失明确；参考为平面模拟，不能直接套其角度到现有球切外壳 |

## 已有真实刚体形变表示，但不是实物机构认证

曲线直升机、太阳二号、蝶恋花、花瓣、双子星，部分棱准备与逆转均通过，全部颜色保留。程序有完整块姿态，而非仅换颜色。

Crazy Comet、六角星金字塔也有刚体与切面阻挡逻辑，不能归为“完全没做形变”；其中曲面尺寸、鼓面近似、不可见材料和复杂交织状态，仍需与实物逐步核对。

Mixup／Plus、SQ、迷彩及镜面迷彩、可形变长方体、Ghost／镜面及若干换壳型号已有独立动态实现。本轮查看机构代码，不等于对这些系列重新做完实物全状态认证。Ghost 的对齐相位是简化表达，尤其不能把任意相位输入理解成任意跨轴转动合法。

## 不要误判成缺少形变

对下面模型逐轴、逐层执行四分之一转，检查所有刚体顶点是否超出初始凸外壳：

| 当前模型 | 结果 |
| --- | --- |
| Trajber四阶 | 无超出，外壳具有对应的四重轴对称 |
| 菱面三阶、四阶 | 无超出 |
| 四阶菱边 `rhombic_mask_4` | 无超出 |
| 八面魔球 `caneball_4` | 无超出 |
| 2×2十二面体、3×3十二面体 | 有超出，最大约0.240818，当前刚体模型已经表示形变 |

这是当前数学模型的结论，仍需与具体商品版本对应。Trajber 等属于换壳，不能因此推断必须形变。普通Floppy与Super Floppy、固定长方体与可形变长方体也必须按具体型号区分。

## 建议修正顺序

普通直升机 → Rua → 核实四叶草版本 → 紫荆花。优先复用已有整块阻挡、部分转角、动画和先复形后求解流程，但每款必须使用自己的切面、隐藏块和实物参考。其余三款待核实后决定是否开放混转。

当前目录和手工输入政策保持不变；没有恢复此前删除的型号。
