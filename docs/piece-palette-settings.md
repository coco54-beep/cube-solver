# 选块录入页的配色设置

移棱、风车、变形金刚等彩色形变魔方，以及粽子系列，顶部的配色色条收为录入操作区的齿轮按钮，点击进入“配色设置”。顶栏统一保留返回、标题和教程；块方向调整按钮仍在翻面箭头之间。

普通魔方保留填色所需的六色工具；高级录入页原滴管改为齿轮配色入口，简洁录入页在翻面及求解操作行提供该入口，不在顶栏单列。共用独立设置页，W/R/G/Y/O/B 标签与展开图一致。普通魔方各阶共用已保存的显示配色，普通模型的录入、拧动、回放和演示使用同一份显示颜色，逻辑颜色键保持不变。自定义显示配色与相机采样校准独立保存。

独立设置页共用 `PiecePaletteScreen`：

- 四色系列显示四面体展开图，六色系列显示六面编号展开图。
- 点带颜色背景的编号按钮，编辑该编号的显示颜色。
- 当前编号在展开图中高亮；显示颜色的预览不修改求解状态。
- 恢复默认仅修改设置草稿。保存后才持久化；取消或返回放弃草稿。
- 沿用已有配色保存方法，保留已经录入的块、块方向、观察方向和撤销历史。
- 纯镜面、鬼魔等没有原配色条的页面不增加无用入口。
- 在设置页切到后台时，会话保存录入页状态；进程恢复后回到录入页，不保存未提交的配色草稿。

桌面横竖屏界面预览：`artifacts/piece-palette/`，普通魔方预览：`artifacts/cube-palette/`。最新统一入口的横竖屏预览和检查记录在 `artifacts/palette-controls/`。

## 入口一致性检查

- 普通魔方 2、3、4、5、6、17 阶，均检查高级及简洁模式。
- 粽子 2–5 阶、变形金刚/移棱/风车 3–4 阶，检查工具区齿轮及共用设置页。
- 检查取消不改色、保存后生效，以及已录入的块、方向和撤销记录保持。
- 检查 BiCube、Bandaged C、Penrose 与普通魔方之间切换，按钮不重复、不留空位；原有吸色动作不受普通配色入口影响。
- 检查镜面、鬼魔及七款镜面形变页不增加无用配色入口；异形通用页、镜面金字塔/斜转等专用页、SQ 页没有额外的“配色设置”文字按钮。

本次 47 项桌面检查通过，使用隔离的偏好设置文件；已查看粽子、移棱的横竖屏和普通魔方的竖屏预览。未运行完整测试套件、未做 Android 真机验证，也未生成 APK。
