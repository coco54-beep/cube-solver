# 花瓣与双子星：合法形变及形变打乱

2026-11-02，源码实现，未打包。

后续修正：用户确认双子星内外小片能错开，并要求按 pCubes 核对。新建双子星已改用参考分块与两类交换，见 [成对同色修正报告](../twins-scramble-coverage/README.md)。本报告的双子星 CAD 分块及通过记录只对应旧版本；花瓣部分不受影响。

## 本轮行为

- 两款保留现有 CAD 外壳：花瓣 161 个完整材料区、120 片颜色；双子星 190 个完整实体（288 个布尔原子区）、192 片颜色。没有切回旧双子星模型。
- 花瓣支持棱 180°、约 70.528779° / 109.471221° 的准备角和角轴 60° 的整数倍。双子星另支持约 54.735610° / 125.264390° 的棱准备角。无效停止角会拒绝执行。
- 每次切面检查整块及隐藏材料。双子星的原子区先合为完整实体；即使各原子单独不跨面，整体跨面也必须阻挡。失败、取消均在写入模型之前返回。
- 已移除双子星转动矩阵强制取整，突出块的位置和所有跨面颜色跟随真实旋转。
- App 的随机打乱使用常规混色加最多两个不同轴的合法形变准备，不把整体转动视为形变。每个步骤经过完整材料检查；没有保存打乱历史供求解器倒放。
- 还原先搜索恢复外形，再进入现有配色算法，最终逐步回放全部物理动作。
- 打开仍是完整配色的模型；保留拧动、打乱、撤销、重置和还原。手工调整形状、摆块和颜色输入入口继续关闭。
- 角度选项接通拖动与按钮，教程与目录名称同步修改。

## 绘制与性能

形变后保留真实的黑色塑料面。通过立方对称下的材料邻接关系，只隐藏能够证明仍贴合的内表面；正在转动的两组材料单独检查。这样不会把突出块的内表面误删，也不必把全部 43,704 / 54,986 个缓存三角面都画出来。可视裁剪不参与转动合法性判断。

## 验证

- 首轮 200 项回归通过：包括原有配色动作群、规则转动、材料清单、形变还原和蝶恋花兼容性。
- 补充 174 项检查通过，记录见 `focused.xml` / `focused.log`：包含原生无录入页面、检查点、撤销、共享形变搜索及最终绘制修改。
- 最终 `test_cad_copter_shapes.py`：39 项通过，见 `shapes.xml` / `shapes.log`。其中 24 个案例为两款各 6 个种子、30 / 100 步混色后形变，经过 JSON 和会话重新加载，再依据当前状态求解、逐步验证回放；不读取历史。
- 原生 App 的两款 × 两种窗口尺寸（800×600、390×844）共 4 页通过，见 `native-results.json`。实际执行角 60° 后再转棱，检查动画、返回、形变页验证、重置、撤销及手工入口保持关闭。
- 截图：`*-twist-*.png` 和 `*-play-*.png`。

## 仍然保留的限制

合法性针对当前 CAD 推导的完整实体模型。实物内部导轨、中央弧的实测半径和安卓真机性能尚未验收。复杂交织形变仍可能复形超时，恢复外形后的新排列也可能超出现有配色动作群；失败保留当前状态，不宣称任意形变均已保证可解。没有新增大型离线表，也没有重新开放手工输入。
