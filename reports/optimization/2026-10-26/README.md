# 深层状态与解法质量

本轮优先处理深层回录测试、缩短解法和 Mixup 的重复计算。沿用当前魔方目录，没有调整分类；只改源码和验证，未打包。

## 深层测试

累计 **81 个型号、240 个不同的型号／种子／步数组合**，均为 30 或 100 步合法随机游走。步数是打乱动作数量，不代表离还原态的最短距离，也不代表各阶数都已覆盖。

| 检查 | 结果 |
| --- | --- |
| 序列化可见输入后重新构建状态 | 240 / 240 |
| 实际求解并独立逐步回放到还原态 | 237 / 240 |
| 60 秒求解预算内仍未完成 | 3 / 240 |
| 已报告的错误解法或录入重建失败 | 0 |

三个未完成案例均为 `mixup_plus_344`：种子 20261102 的 30 步，种子 20261104 的 30 步与 100 步。计时到期后由测试工具主动取消，不能据此判为无解或非法输入。定位到的主要热点是几何修复阶段的宏动作枚举；本次缓存加速尚未让这三例在 60 秒内完成。

测试边界只跨越可见颜色、六视图或实际录入组成／方向。求解器不接收源打乱历史、源块身份或源姿态数组；每个案例清空解法与搜索断点缓存。新状态由生产匹配／录入模型重建后交给实际求解服务。工具层验证可见状态一致及历史为空；成功解法在克隆上逐步检查真实模型动作并确认还原，不修改原输入。

这是数据层回录，不是 240 次手机点按或拍摄测试。随机模型规则也没有替代实物机构认证。

### 分批记录

- `deep-30`、`deep-100`：原 39 个适配型号各一个新种子，78 例，12 秒求解预算。
- `deep-isolated`：同 39 个型号换种子，各测 30、100 步，78 例，20 秒求解预算；每例独立进程。
- `additional-inputs`：新增 42 个数据录入适配型号，各测 30、100 步，84 例全部通过，包括字母扩展、其余长方体、固定面多面体和花瓣型号。
- `deep-retry-60`：9 个短预算未完成案例延长到 60 秒，6 例通过。
- `mixup-fast-retry`、`mixup-shell-retry`：缓存与几何去重改进后重测剩余 3 例，仍未在预算内完成。
- `mixup-final-production`：最新 Mixup 改动后，八种 Mixup 的指定 100 步案例全部通过。

汇总按型号／种子／步数去重，重测用最新结果覆盖，见 `matrix-latest.json`、`summary.json`。这是本轮逐步改动期间的累计记录，不宣称所有 240 例都在最后一个源码版本上重跑了一遍。

## 解法缩短

1. 新增固定面型号及 Master Brilic 接入已有的相邻动作化简、可交换动作合并和完整状态回环删除。
2. 增加有预算和缓冲上限的状态捷径比较：若原解中两个完整颜色状态之间可用一步合法固定层转动连接，则替换较长片段。颜色状态使用完整数据比较，候选最终须完整回放；不把这种颜色化简用于变形机构。
3. Master Brilic 的单贴片轨道增加按颜色规划三循环。复用已建立的运输树估算准备动作，比较宏公式与阶段衔接成本；同色块无需回到指定身份。保留原有标号方案，只有更短且所有目标及外部贴片回放一致时才接受。

`brilic-paired-quality.json` 对同一份可见输入分别关闭和开启本次颜色规划，再独立回放两个完整解法。六例全部缩短：

| 原解步数 | 新解步数 | 减少 |
| --- | --- | --- |
| 3064 | 2733 | 331 |
| 2840 | 2564 | 276 |
| 3122 | 2847 | 275 |
| 2374 | 2126 | 248 |
| 3142 | 2839 | 303 |
| 2670 | 2370 | 300 |

步数按软件播放动作统计。可选规划含时间预算，不承诺所有设备都返回相同序列或最优解；这些结果也说明部分解法仍有两三千步，尚需继续改进。

## Mixup 重复计算

保留每个物理状态不可变的块特征，在现有有界缓存中复用可转切面的交集与倾斜评分；特征表命中时减少 Python 层逐块生成器遍历。几何修复的中性准备动作按完整外形去重，避免因颜色置换不同重复探索相同机构；颜色还原阶段保留原规则。

`mixup-feature-benchmark.json` 在三种型号各 10000 次同样的动作查询上与旧逐块检查作差分，结果完全一致，局部查询速度约为原来的 **1.45～1.66 倍**。这是小范围热点对比，不是整个求解、安卓启动或手机性能倍数。

## 自动回归与复现

自动测试按名称去重 **273 项通过**，包括原输入不变、取消／截止、错误候选回退、九类固定面动作等价、八种 Mixup 的实际转动合法性、同外形后继切面一致性、实际录入和续算回归。原始文件见 `regression.xml`、`mixup-fast.xml`、`quality-latest.xml`、`final-quality.xml`。

```powershell
python tools/audit_deep_input_matrix.py --all --seed 20261104 --turns 30 --turns 100 --budget 20 --jobs 2 --out reports/deep-recheck
python tools/audit_deep_input_matrix.py --retry-from reports/deep-recheck/results.json --budget 60 --jobs 2 --out reports/deep-retry
python tools/benchmark_mixup_features.py
python tools/audit_brilic_quality.py
python -m pytest tests/test_deep_solution_quality.py tests/test_mixup_reduction.py
```

当前 `--all` 包含扩展后的 81 个适配型号；`--additional` 只跑新增的 42 个。失败案例保留独立输入、结果及日志。独立进程的额外看门时限覆盖匹配和回放，防止不响应取消的单例卡住整批检查。工具在任何案例未被证明还原时返回非零退出码。

关闭软件后的磁盘搜索续算、安卓真机性能及实物机构核对尚未在本轮完成；现有进程内续算机制保留。没有制作安装包。
