# Coin Tetrahedron（硬币金字塔）

入口：首页 → 特殊异形 → 硬币金字塔 · Coin Tetrahedron。

采用奇艺 Coin Tetrahedron 的圆盘及转角结构。四个角块、12片独立椭圆叶片、4个单色面中心，共20个可见块、28个色面，每面7块。

## 模型及转动

每面外圆是三角形内切圆，三个外侧角片与三个椭圆叶片共用圆弧边界；内弧以顶点为圆心，经过相邻棱中点，围出中央曲边三角。面中心和切割比例采用理想几何，不含塑料圆角。

- C1–C4：四个面圆盘，120°转动，只循环本面三片椭圆叶片；中央曲边三角随圆盘转动，单色不区分朝向。
- V1–V4：四个角，120°转动，转动该三色角并循环它相邻的三片叶片。
- 支持对齐切口后的120°落位状态。圆盘停在两档之间的连续角度状态暂不录入。

录入、触控、随机打乱、回放和保存共用同一份块位置换。四面观察沿相邻棱逐面进行。

## 求解

1. 校验颜色总数、固定面中心、角块颜色顺序和叶片轨道。
2. 独立恢复四个三色角的方向。
3. 用圆盘原生三循环及其共轭处理12片椭圆叶片；公式结束后已完成的角和中心保持原状。
4. 从输入状态逐步应用求解结果，确认全部色面完成复原后返回。

运行时不建立大型全状态表，叶片三元组搬运树只有12³个槽位。此构造解不保证全局最少步数。

教程提供8个典型“角已齐、跨面叶片错位”情况，展示“转角 → 转圆盘 → 角转回”的公式。每例均从对应待还原状态开始。
