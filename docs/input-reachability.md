# 录入匹配与可还原性

## 两种结论

颜色数量、形状、块位能组成一个模型，不能单独证明该状态可由合法转动得到。绑块和变形魔方还受机芯、切面、连块和转角限制。

- 确定违反某项必要条件：拒绝录入，并指出颜色、朝向或轨道问题。
- 结构匹配通过，但尚无可达性证明：允许保留、编辑和尝试求解，不能称为“保证有解”。
- 找到解法且在原输入上完整回放成功：确认当前状态有解。
- 有限搜索未找到解：只说明本次未完成，不能据此断言无解。

## 2026-10-23 修正

`cube/validation.py` 增加或修复以下检查：

1. 二阶的角块扭转基准采用角块实际的 U/D 颜色。旧实现取当前位置朝上的颜色，使扭转检查恒为零。
2. 二阶、三阶及更高阶检查角块贴纸的刚性手性，拒绝三色数量正确的镜像角块。
3. 四阶继续检查角块组合、角扭转总和、翼棱身份与方向，不能只检查每色数量及块数。
4. 五阶增加三阶核心的角扭转、中棱翻转与奇偶条件，并检查翼棱和中心各自的轨道。
5. 四阶及更高偶数阶保留合法的翼棱奇置换，不把正常的降阶特殊情况误判为非法。
6. 六阶以上的面色输入复用这些不依赖打乱历史的检查。校验只需几何与颜色信息，不为此加载三阶求解表。

绑块录入通过模型重建后，提示改为“连块与配色匹配通过；尚未确认能否还原”。Mixup / Tangram 的结构匹配也仍与实际求解结论分开。

## 适用范围

这些标准魔方检查覆盖已实现的颜色、实体朝向和轨道约束，不能代替不同异形型号额外的机构限制，也没有增加任意绑块或 Mixup 状态的完整可达性判定器。输入错误、机构不可达、求解器计算限额及程序错误必须分别处理。

验证包括四例旧版会接受、现已拒绝的非法输入，以及合法随机转动、偶数阶特殊情况、二至十七阶面色录入和各绑块型号重建。见[验收记录](../reports/input-audit/2026-10-23/reachability.md)。
