# 直接录入实物形状

## SQ-1、SQ-0、SQ-2、Super SQ-1

- 新建录入从空层开始。青色线标记起点，沿箭头顺序录入；选中空位有青色边框。
- SQ-1 先选大小块，再输入顶色和侧色，完成后自动选中下一空位。
- 其他 SQ 从实物形状与颜色卡片中选块，放置后自动前进；一层填满后进入下一层。
- 已用块不会重复出现在卡片候选中。Super SQ-1 内外层分别筛选。
- 选已有块可修改；不得覆盖邻块。撤销恢复块、位置和颜色。
- 层的旋转仍可用于对齐实物切口，中层状态单独设置。完整后沿用型号的块数、颜色和切口检查。

## 长方体与迷彩

- 不能变形的标准 3×3×2、2×2×3、3×3×4 沿用原来的颜色输入，隐藏摆块入口。
- 可变形型号和迷彩直接进入正式六视图页面，替换旧“直接摆块”弹窗。
- 前、右、后、左、上、下按实物框选同一张面片并填色；不再选择内部块编号或枚举位置。
- 小网格是采样位置。一个色块跨多个格时拖框连接；相邻同色的不同块分别框选，保留切缝。
- 空位、黑色塑料、未录分别表示。录完本面的色块和塑料后可一键把其余未录处标为空位。
- 高度默认自动匹配；有歧义时补充选中区域从外向内的高度层。
- 撤销保留观察草稿；设置配色、返回录入、应用切换后台均保存草稿。拧动后返回会更新六视图，也可撤销该次拧动。
- 后台按现有几何、刚性块占位与遮挡匹配，唯一匹配后应用。缺失、冲突、歧义或时间用尽均保留草稿，不会任意挑一个候选。
- 2×2×4、3×3×5、4×4×6、2×3×4 已改成核心与外层延伸分别建模。结构匹配不等于完整可解性证明。
