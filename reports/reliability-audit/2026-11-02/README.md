## 修正内容

1. **损坏存档的恢复校验**：此前会过滤格式错误的页面数据，随后继续替换当前魔方。现在先检查页面字段、魔方对象、阶数及配色数据的基本结构，错误存档在修改当前状态前被拒绝。补充了错误字段、非法魔方对象、阶数冲突和配色类型异常的回归案例。
2. **旧页面正常迁移**：合法存档里已移除或改名的页面，仍可回到首页并保留合法魔方；与格式损坏分别处理。
3. **后台恢复兼容检查**：先确认教学页存在，再检查是否需要恢复其媒体状态；保留跨帧刷新与画布顺序检查。
4. **测试相互隔离**：七款模型操作页测试不再在收集时全局加载界面规则，避免污染其他独立控件测试。桌面五阶预热测试明确隔离安卓环境变量并模拟资源加载，另验证安卓继续延迟预热。
5. **当前目录检查工具**：识别七款仅操作模型的页面，不再把用户已删除的“清空录入”当作必需按钮。

235个入口检查包含重置、撤销、清空确认／取消及撤销；七款仅操作模型的页面按当前规则检查，未恢复颜色或形状录入。76项界面检查没有打开物理摄像头。
