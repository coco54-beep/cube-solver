## Android 与平台边界

- Java 辅助类按 Android API 33 编译通过。
- 使用 API 33 模拟器直接运行原生编码辅助类，完成 RGBA→H.264、PCM→AAC、音视频合成 MP4；输出 `android-native.mp4`，日志见 `android-native-final.log`。检查不需要构建或安装新 APK。
- 模拟器没有系统语音引擎，**Android 系统 TTS、应用到原生编码器的完整连接及系统文件选择器保存，尚未完成手机真机联测**。桌面中文语音与完整导出已经实际运行。
- Windows 导出需要可用的 FFmpeg；Android 使用系统编码器，不增加 FFmpeg 二进制依赖。未找到所需语音或编码器时显示失败信息，不静默丢弃已勾选的旁白。
