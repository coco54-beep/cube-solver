# 异形魔方

## 已接入的范围

| 类型 | 阶数 | 录入方式 | 求解与回放 |
|---|---:|---|---|
| 金字塔魔方 | 2–7 | 贴纸颜色；二阶单独建模四个可动尖角 | 支持；多面体几何回放 |
| 镜面魔方 | 2–9 | 按块形和朝向录入，不输入颜色 | 支持；回放校验块尺寸与位置 |
| 斜转魔方 | 3、5、7 | 贴纸颜色 | 支持；顶点转动几何 |
| 五魔方 | 2–13 | 十二面颜色；偶数阶对应 Kilominx 机构 | 支持；小阶核心搜索，高阶轨道降阶 |
| 魔塔魔方 | 3–7 | 贴纸颜色与多面体切层状态 | 支持；使用专属转动置换 |
| 粽子魔方 | 2–9 | 异形块颜色与朝向 | 支持；三阶专用中心朝向模型，高阶按块身份求解 |

异形目录、录入、拧动和演示均有独立页面。5 阶及以下的演示入口沿用普通魔方的分步播放交互；播放器保留对应外形，并支持速度和停留时间调整。界面开放的阶数代表当前实现范围，不等同于所有可达状态都已完成系统性性能评测。模型按各谜题的合法转动结构生成状态和回放，不把异形外观误当作普通三阶贴纸布局。

## 录入与控制

在还原状态下确认各面配色。模型标出的面号对应色条中的色号；选中色号后，用齿轮调整为实物颜色。配色会保存。
打乱状态下选色、点击对应色块完成录入。点击和拖动不会改变镜头；左右箭头会带动画切换观察面。

转轴、层数选择要转动的层，相邻的弯箭头正反转该层。随机图标生成合法打乱状态；垃圾桶清空录入；撤销恢复上次编辑；勾选检查颜色数量、块组合与朝向；播放图标开始求解。

镜面魔方通过块形状卡片录入，旋转箭头调整块朝向。粽子继续使用现有形状和配色录入。
设置中的使用说明、录入页的书本按钮均介绍这些控制。

## 求解和回放

求解只使用当前录入的状态，不依赖随机打乱记录，也不是简单倒放打乱步骤。

- 二、三阶五魔方采用强生成序列；高阶先处理低阶核心，再用独立三循环处理增加的棱块和中心。
- 金字塔、魔塔、斜转先搜索小核心；短时间搜索未完成时采用构造式解法，然后还原新增块轨道。
- 金字塔独立的顶尖最后单独处理，减少核心搜索的重复分支。
- 镜面借助普通 NxN 机构求解，结果再用实际偏心块几何核对。
- 粽子继续使用现有二阶、三阶和高阶求解器。

高阶解法以能还原为目标，步数较多，可能达到数千至数万步，并非最短解。
求解放在后台，可取消；长距离跳转也放在后台，并保存每 128 步的检查点。
演示页的左右箭头执行上一步、下一步，支持播放、暂停、回到起点、跳到终点、进度与速度调整。

开发检查覆盖新增阶数的随机状态求解和还原回放，以及横竖屏、点选、转层、上/下一步、跳转、返回和取消。
十三阶五魔方的一轮桌面求解约 70 秒；手机性能及所有录入状态尚未穷举验证。

## 几何和算法资料

- [cubing.js 的公开几何定义](https://github.com/cubing/cubing.js/blob/main/src/cubing/puzzle-geometry/pgPuzzles.ts)：金字塔、斜转、奇数阶五魔方切割结构。
- [cubing.js Megaminx 强生成序列](https://github.com/cubing/cubing.js/blob/main/src/cubing/search/inside/solve/puzzles/dynamic/sgs-side-events/megaminx.sgs.ts)：数据及许可见 `solver/data/README.md`。
- [Rob 的实物收藏与四面体结构分类](https://robspuzzlepage.com/rearrangement.htm)：Fourth/Sixth Magic Tower 与其下一个奇数阶 HMT 的删块关系。
- [五阶魔塔实物与解法记录](https://abnormalcube.blogspot.com/2021/10/?m=0)：Master Skewb 结构、边分成五段，与 Jing's Pyraminx 的关系。
- [Jaap 的四轴谜题结构说明](https://www.jaapsch.net/puzzles/ideas.htm)：HMT、金字塔与斜转的机构关系。
- [Grubiks 的 Mini Pyraminx 说明](https://www.grubiks.com/puzzles/mini-pyraminx-2x2x2/)：二阶金字塔只有四个尖角可以独立转动，中间三角块固定；不能沿用 Duo 转动规则。

魔塔三、五、七阶每面分别为 7、19、37 个色块；四、六阶每面为 12、27 个色块。
奇数阶魔塔采用 HMT 浅切结构，中心块为与外轮廓同向的三角形。五阶的切面距离为 `0、1/3`，七阶为 `0、5/18、5/9`（以四面体内切球半径为单位），用于模型、录入命中与转层置换的同一套几何数据；不使用绕中心对称的切割距离。
偶数阶五魔方每面为 `5 × (阶数 / 2)²` 个色块。
转层使用几何位置导出的精确置换，求解回放核对这些置换；同一色块还检查转动前后的多边形位置一致。

## 五阶及以下的演示

录入页的书本按钮打开演示目录。支持目录中已有的金字塔、粽子、镜面、斜转、五魔方和魔塔，阶数不超过五阶。沿用普通魔方的案例缩略图、横竖屏布局和逐步播放：左箭头撤回一个动作，右箭头执行一个动作，播放键连续播放，首步键回到案例开头，圆箭头恢复观察角度。滚动目录不会直接打开案例。

每个案例使用独立模型，并以显示公式的逆操作构造起始状态，不改变录入草稿。镜面使用对应阶数的普通魔方动作；三阶粽子保留原有案例，其他粽子阶数补充角块与宽层示例。多面体使用自身合法转轴和层的置换进行动画，二阶金字塔仅转四个尖角，中间三角块保持固定。`A1:1` 表示拧动页的第一个转轴、第一层，撇号表示反向；五魔方每次转 72 度，金字塔、斜转和魔塔每次转 120 度。

新增多面体案例用于学习转轴、转层和组合动作，尚不是覆盖所有打乱状态的完整还原课程；录入后的完整还原仍使用求解功能。

## 异形拧动交互

录入视角：镜面与斜转使用普通高级输入的 `F → R → U → B → L → D` 六面顺序，正对当前面并以整体现示旋转动画切换。粽子 2–9 阶沿用三阶粽子的机械六面顺序与初始视角。金字塔与魔塔共用按面号 `1 → 2 → 3 → 4` 循环的动画切换，并保持三角面尖角向上。左箭头逆序切换；动画期间暂时锁定录入操作，返回或离开页面时释放动画状态。视角变化不修改录入块的位置、颜色或求解状态。

外形显示：粽子 2–9 阶统一使用原二、三阶的平滑曲面轮廓，高阶沿该曲面增加机械切层。魔塔 3–7 阶改用原四阶粽子的球面片四面体轮廓，保留魔塔自己的切块编号、中央三角形布局和转轴。显示网格与边线预先缓存；曲面点击和拖拧使用实际显示面的接触点。此调整不改变颜色录入数据和求解置换。

拧动页默认锁定视角：按住块并拖动，松手后转动该块所在的层。按实际接触位置的运动方向选择转轴；轻点、空白处拖动和方向不明确的斜拖不转层。解锁后拖动只改变视角；撤销、重做和恢复视角与普通魔方拧动页一致。粽子、镜面支持拖动内层及外层宽转，未录入的块随转动保持未录入。返回时保留已完成的操作，转动动画期间不接受新的手势。
