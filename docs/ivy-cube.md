# 枫叶魔方（Ivy Cube）

作为第 12 个特殊异形加入：异形魔方 → 特殊异形 → 枫叶魔方。
厂家目录：[奇艺魔方格枫叶 M](https://www.qiyitoys.net/h-col-103.html)。

## 模型和操作

- 四个相间的角为转轴，每次转动 120°。
- 每次转动自己的三色角块，同时循环移动相邻的三个叶形中间块。
- 四个角块、六个叶形中间块；每面三个色面，共 18 个色面。
- 面上的两条圆弧以相间角为圆心、棱长为半径，围成叶形块；采用共享圆弧和圆角外壳。
- 六色录入、默认配色恢复、随机打乱、触摸拧动及横竖屏逐步回放沿用异形魔方界面。
- 演示入口沿用现有逐步演示，介绍角转和叶形块交换。

## 求解

`scripts/build_ivy_moves.py` 从实际转动生成完整颜色状态图，以还原态为起点进行广度优先构造。
表中覆盖 29,160 个可达状态，最远距离为 8 次转角（120° 和 240° 各计一步）。
运行时直接根据用户录入的四个角朝向和六个叶形块的位置查表，得到最短步数解法。
不依赖打乱历史；不可达状态会提示检查录入。最终状态仍作完整回放检查。

本次生成了求解数据，没有运行随机求解测试，也没有构建安装包。
