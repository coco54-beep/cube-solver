# Fisher Skewb（移棱斜转）

入口：首页 → 特殊异形 → 移棱斜转 · Fisher Skewb。

采用 MoYu / Nathan Wilson 的 Fisher Skewb 改型：普通斜转机制、相对机制绕一轴旋转45°的立方体外壳。两个面有方形中心，另四面呈 X 形分割。每块都有刚性立体表面和独立朝向，打乱及播放时会真实变形，不以普通三阶移棱模型代替。

## 输入与操作

点选模型中的位置，再从卡片选择实物对应的颜色与形状；中央按钮切换可见方向。左右箭头按外壳的真实六面方向切换。两个单色方形中心的不可见半转方向合并显示，侧面中心的可见方向仍需录入。

触控转动、镜头、撤销与还原播放使用公共斜转界面。退出、切换应用后的状态保存包含真实块位与朝向。

## 求解与教程

先还原虚拟斜转状态，再用预制公式处理可见中心方向。忽略两个方形中心在外观上无法区分的半转，避免因为隐藏标记而拒绝正确录入。每次返回最终解法前从录入的实体状态完整回放，核对颜色、外形及可见方向。

`python tools/build_fisher_skewb.py` 离线生成 `solver/data/fisher_skewb.bin`；覆盖32种合法的机制中心朝向组合，带机制指纹。手机无需重新建立中心朝向搜索表。教程提供4个“单个侧中心方向错误”的典型情况。

外壳比例为标准几何近似，没有厂商 CAD 或实物测量；尚未做手机和实物录入验证。本次未重新打包 APK。
