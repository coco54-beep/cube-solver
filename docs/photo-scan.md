# 拍照识别

首页相机入口先选择类型，再选择阶数。支持的异形录入页右上角也有相机入口，
可以继续已有的录入。所有拍照入口最高五阶，不改变其他录入方式支持的阶数。

## 使用

1. 将小模型当前显示的面正对相机，保持顶点、边和切线方向一致。
2. 拍照或导入图片，拖动各顶点，让框内切线与实物吻合，再点“按框识别”。
3. 用左右箭头观看整体翻面动画，按相同方向翻转实物，继续拍下一面。
4. 颜色相近或受光线影响时，点“取色校准”，选择录入页对应的颜色编号，
   再点照片中该颜色的色块内部。校准会重新处理已经拍摄并定位的照片，保留手动改色。
5. 点小模型的色块可以改色；问号代表未确定。普通多面体允许将部分识别结果转入大模型补录。
   潘多拉需要六面完整且通过块组合校验，才会转换为现有的块与方向录入。

校准只作用于本次拍照会话。颜色编号与求解器一致；深色、近似色和不确定的取样保留为空，
不按预期颜色数量强行补齐。二十面体的二十色、足球的三十二色尤其需要在同一光线下校准。

## 实现边界

- 异形从现有模型的贴纸轮廓和凹多边形三角剖分生成取色区域，避开切缝及空洞。
- 正方形使用四点透视变换；五边形、六边形使用多点透视拟合；三角面使用三点仿射变换，
  因而需要尽量正对三角面拍摄。
- 识别的是当前模型所支持的正常拼形状态。四叶草、繁花等的错层／变形玩法不在模板范围内。
- 这次变更进行了源码语法检查；尚未用新增类型的手机实拍照片验证准确率。
