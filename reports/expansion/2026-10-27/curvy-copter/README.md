# 魔蝶：球切模型的生产流程

目录沿用“棱转系列”，明确显示“魔蝶 · 球切模型”。这不是本批全部完成，也不把实物内轨未核对的范围写成已经验收。

## 本轮接通

- `CopterCube` 将观察到的 45 个刚体朝向与 72 片颜色分开保存；44 个有色块及核心沿用解析切割模型。播放检查点携带形状和颜色，首尾跳转不会丢失姿态。
- 输入页沿用选色、连续上色、配色设置、逐面动画、六个动作按钮、跟随镜头及统一失败提示。调整形状放在一个按钮里，打开后才显示块位与角度控件。
- 形状弹窗可点选整块，所选块的所有色面共同高亮；拖动预览可观察背面。只调整选中块时，其他块和全部颜色保持。整层模式检查实体阻挡；确认才应用，取消不修改输入。
- 提供 X/Y/Z 与十二条棱轴，90°、180°、精确 J/180°−J 和自定角度。J 的计算用 `acos(1/3)`，不会把显示四舍五入后的 70.529° 当作准确解锁角。
- 拧动页支持角度选择、按钮及拖拧、撤销和重做。所有实际动作经过整块检查；被阻挡时不会写入撤销历史或强行转到其他角度。
- 打乱先执行经过认证的闭合混转组合来交换叶片组，再产生合法非立方外形。任务在后台运行；取消或过期回调不覆盖当前输入。
- 生产求解服务从当前观察状态独立复形及配色还原，不读取打乱历史；每一步在完整实体上重播。颜色资产 10349 字节，运行时不使用 SymPy。
- 正式会话序列化、录入及拧动路由、目录缩略图和原创四章教程同步接通。四个本地案例展示常规转层、部分准备和撤回复形；没有复制外部教程。

## 验证

- `reports/copter-production-tests.xml`：145 项相关测试通过。包含完整实体、闭合曲面、独立颜色群、30/100/300 步观察重建、生产服务、检查点/JSON、输入保留以及公共取消/失败流程。
- `reports/copter-production-final.xml`：17 项定向及课程/会话检查通过，含全部 44 个有色块分别旋转四次 90°后仍能求解的回归。与上一组有重叠，不相加计数。
- `tools/audit_copter_entry.py`：800×600、390×844 两个原生 Windows 窗口通过目录进入、连续像素点选、单块编辑的确认/取消、清空的确认/取消/撤销、阻挡、拧动撤销、独立求解、回放首尾跳转、打乱后撤销、取消打乱及输入保持。两个案例均 258 步，见 `visible/results.json`。
- 观察重建测试从生成状态取得测量朝向，经 X/Y/Z 数值控件逐块重建，再逐片填色；没有把源状态直接替换成输入对象，也没有传入源打乱动作。但这是自动测量的合成观察测试，不能当作真人看着实物输入的可用性验证。
- `teaching/controller-results.json`：实际书本入口、章节跳转、四个案例的前进/后退及中途取消通过。

## 尚未完成

- 目前外壳/阻挡依据球切参考；LanLan 实物切面、内部轨道和制造容差没有实测核对。基础机构和混转现象可参考 [设计者原型模拟器](https://github.com/spencerparkin/TwistyPuzzle/blob/master/Source/Puzzles/CurvyCopter.cpp)，但参考几何不构成实物机械认证。
- 通用数值姿态控件能表达参考模型的状态，操作负担仍高；还需便捷的视觉形状匹配与真人录入测试。
- 困难变形仍可能复形搜索超时。超时保留输入并允许重试，不将它说成无解，也不宣称任意状态完整覆盖。
- 未做安卓真机性能或实物手拧验收，没有打包。本批清单仍将魔蝶列为有限范围，尚未完整完成数量不扣除它。
