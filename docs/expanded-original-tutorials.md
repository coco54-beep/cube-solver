# 新增魔方原创分步教程

本教材按本项目的 32 个实际模型编写，与应用内“原创分步教程”的章节和三维案例对应。
每款含机构识别、主体处理、余块工具和逐面验收四章。公式的起始状态必须在三维案例中核对；完整还原演示则从独立打乱状态求解。
三块循环工具由合法转层推导并检查完整作用范围；核心公式同样按块位和方向检查，不转载外部教程或链接。

## I-Cube

I-Cube：三阶核心加 1 个方向的扩展层。先辨认三阶核心，再处理扩展块。

### 一、识别机构与建立参照

**识别**：观察三阶核心的角、棱与中心；扩展中心与核心相连，不能把外观格数当阶数。

1. I-Cube：三阶核心加 1 个方向的扩展层。先辨认三阶核心，再处理扩展块。
2. 先跟随练习一走一步，再退回原位。观察哪些贴片属于同一个刚性块，记住所选轴与转动方向。
3. 转动整个观察模型只改变视角。做公式时保持转轴所指的实际层一致，不随镜头位置重新命名转层。

**完成条件**：能指出参照块、可转层和一块的全部可见面。

**容易出错**：不要把装饰线、三角网格或被遮住的塑料边当作新增块。

### 二、完成主体与安排工作区

**识别**：先对齐需要转动的扩展平面。转层必须完整，不能穿过尚未对齐的扩展块。

1. 先把核心看成三阶。以相连的中心和角棱的相邻颜色确定上下前后，不以最外层长短判断机械面。
2. 转动核心面时让附着的外伸块一起移动；需要转独立外层前，先把该平面的九格补成完整平面。
3. 核心完成后分别使用外伸角组和外伸棱组的循环工具。工具末尾核心必须恢复，不能把核心临时移动当成新的配色方案。

**完成条件**：参照关系确定；已完成部分能在完整操作结束后保持；未完成区仍有可操作空间。

**容易出错**：只看中途画面会误以为公式破坏了已完成部分。完成整段和撤销设置后再判断。

### 三、使用图示工具处理余块

**识别**：还原三阶核心时，记录扩展层的配色与朝向；三阶核心完成不代表外壳已经完成。

1. 先打开“原创三块循环”或“机构公式”案例，比较起始块位、朝向与实物。编号表示工作位置，不表示某种固定颜色。
2. 用合法设置动作把要处理的块送进工作位置，并记录设置顺序。变形机构还必须让公式所需的转层完整。
3. 完整执行图示公式。若需要反方向循环，把整段公式倒序并逐步取反；不要只改其中某个箭头。
4. 将设置动作倒序并逐步取反，原路撤回。一次只确认本工具承诺的作用范围，再选择下一组目标。

**完成条件**：本组目标改善；三块循环的其余块在末态保持，方向工具则符合它展示的起始条件。

**容易出错**：不同轨道、不同形状或不同贴片数的工具不能随意互换。只剩一对错位时先核对整体对齐、配色与奇偶关联，不能硬用三循环假装交换两块。

### 四、逐面验收与完整实例

**识别**：通过准备动作、交换与撤回准备动作整理扩展块，最后检查全部外伸面与轮廓。

1. 逐面旋转模型，检查块位、颜色和外壳接缝；单个正面看似完成仍可能遮住反面的错误。
2. 播放本型号的完整还原实例。先核对它的起始状态；右箭头执行一步，左箭头撤回一步，复位可重新观察。
3. 自己的实物若处于另一种打乱，用“按我的录入还原”生成对应过程；将遇到的设置和余块情况再与本教程的工具比较。

**完成条件**：颜色目标、可见方向和外形目标同时完成；也能解释一次设置为什么要按相反顺序撤回。

**容易出错**：完整实例的动作只适用于它显示的状态；不能在另一种打乱上照抄整段。
