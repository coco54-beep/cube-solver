# 按键逻辑与界面缺陷检查（2026-10-24）

## 范围

检查现有录入、选块、配色、相机、拧动、求解过渡、取消、回放、公式与练习相关逻辑。
静态梳理 30 个页面文件中的 184 处显式 `on_press`／`on_release` 绑定；这个数字不含公共控件动态生成的全部按钮，也不代表逐一触摸过每个按钮。

## 已修复

| 问题 | 修复与覆盖 |
| --- | --- |
| 换位置后，旧候选卡片的延迟点击可能修改新位置 | 候选卡片每次重建获得独立标识；粽子、镜面、镜面塔及继承页面、SQ 系列、Tangram、彭罗斯忽略过期卡片回调。 |
| 镜头动画或后台处理期间仍能改录入 | 普通录入、按块录入及相关换面动作统一检查忙碌状态；多面体拧动页禁止镜头尚未停稳就再次换面。 |
| 求解页尚未完成进入就取消，可能报错或继续启动旧任务 | 配置时记录返回页；取消清除待启动任务及运行标识，延迟进入不再启动旧求解。 |
| 重复求解请求覆盖正在运行的任务，导致新请求停留在待启动状态 | 求解页已有活动任务时保留当前请求；取消后可重新配置并启动新任务。 |
| 取消后旧结果或旧进度影响新请求 | 使用任务标识过滤过期结果和进度，新增取消、重新进入和延迟结果检查。 |
| 切页后松开原页面按住的按钮，仍执行旧操作 | 公共按钮在松手时校验所属页面；切页时关闭原页面确认弹窗。 |
| 超过 12 色的配色页越界、颜色按钮横向挤压 | 参考图按颜色数扩充编号；色块使用最多六列、可滚动的多行布局，参考图随横竖屏空间调整。已查看 32 色横屏、竖屏及滚动到底的实际渲染。 |
| 重建配色页后，旧色块可能访问新配色的无效下标 | 色块回调校验批次和下标，旧 32 色按钮不能影响后来配置的 4 色页面。 |
| 旧相机换面回调可能错误结束后来开始的新换面 | 每次换面使用独立标识，取消立即作废；旧回调不改变新换面的朝向和忙碌状态。 |

## 验证记录

- [完整回归结果](final.xml)：**599 项通过，4 项跳过，0 失败、0 错误**。4 项为对应 Mixup 型号没有可编辑内棱而跳过，未将这些项算作通过。最终合并检查耗时约 164 秒；机器可读汇总见 [results.json](results.json)。
- 新增 **28 项**按键缺陷回归：[test_button_logic_audit.py](../../../tests/test_button_logic_audit.py)，包含动画中操作、过期卡片、求解取消与重入、彭罗斯联动、配色、过期按钮释放、弹窗及相机回调。
- [实际界面操作链](entry-button-matrix.json)：**34 个代表型号全部通过，合计 257 次动作**。覆盖设为还原态、撤销、再次设为还原态、清空、取消清空、确认清空、撤销清空。Mixup、Mixup Plus、Pentacle 直接清空；迷彩和变形长方体六视图直接清空当前面，因此这些页面不执行弹窗的取消与确认动作。
- [显式按键绑定清单](button-bindings.json)。
- [32 色竖屏](palette-32-portrait.png)、[滚动到底并选择第 32 色](palette-32-portrait-bottom.png)、[横屏](palette-32-landscape.png)。
- 按键规则文档：[button-behavior.md](../../../docs/button-behavior.md)。

操作链比较逻辑模型和录入状态，按无序集合的语义比较，并使用模型克隆排除已失效的来源历史元数据。它不将集合迭代顺序或无效来源历史视为用户录入变化。

## 型号与动作覆盖

普通二／三／四阶、彭罗斯三／四阶、BiCube、三／四阶粽子、镜面三阶、Blanker、Axis、Trajber 四阶、Ghost、镜面塔、镜面金字塔、镜面斜转、Fisher Skewb、Container、镜面二／三阶五魔方、Megaminx、FTO、Dogic 20 色、固定长方体、迷彩三阶、变形长方体、Mixup 三阶、Mixup Plus 四阶、Tangram、Tangram Extreme、Pentacle、SQ1、SQ2、Super SQ1。

另有既有回归覆盖 Mixup 各型号的局部组合、旋转、其他位置不受影响、颜色保留、连续上色、撤销、打乱失败保留输入，以及完整转一圈后恢复可求解状态。回放检查覆盖暂停、单步、等待、跳转与重建，公共页面检查覆盖切换与会话保存恢复。

## 复现

在项目根目录运行 `python tools/audit_entry_buttons.py` 可重新执行 34 型号操作链；需要本机 Kivy 图形环境，会生成本目录的操作记录，过程使用独立应用实例，不启用自动保存及求解预热。

## 适用范围

本轮在 Windows 桌面 Kivy／ANGLE 环境验证，横屏 800×600，配色竖屏 400×850。尚未进行 Android 真机触摸和系统返回键检查，也未重新打包。

这是按键、状态隔离与操作回归检查；不等于保证所有型号的任意深层手动状态均可求解。算法覆盖及运行时限仍应按各型号的求解检查记录判断。

目录中的 `before`、`expanded-before` 等 XML 保留修复前的复现记录，旧的 `model-controls-final.xml` 是修正测试替身前的中间结果，不能作为本轮最终结论。完整最终结论以 `final.xml` 为准。
