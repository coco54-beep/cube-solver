# 手动录入后的还原：2026-10-23

验收流程是：生成合法打乱 → 读取外部可见的颜色、形状和切缝 →
在空白模型上重新录入 → 确认没有打乱记录 → 求解 → 在完整实体模型上逐步回放。
算法测试中的自动录入与真实控件测试分开报告，均不是手机实物测试。

## 2026-10-24：补齐小型绑块、二阶与五阶的接续路线

- Two-Bar、Bandaged C、BiCube 改用完整无色布局图和基准布局配色群，
  分别穷尽 4／25／440 个布局、36／135／1896 条有向合法转动边。
  离线生成时检查全部图边的群成员关系，并逐条实体回放导出的公式。
  手动还原不再依赖旧距离表的浅层覆盖或普通三阶的非法拆块路线。
- 二阶以角置换、角扭转投影距离寻找短解；快速阶段到时后，将真实角块
  嵌入合法虚拟三阶继续还原。虚拟棱吸收奇偶性，不改变录入的角块。
  每个结果均在原二阶上回放，不因五秒短解预算耗尽直接失败。
- 五阶配棱阶段失败或超过快速预算后，接独立轨道交换子算法。
  修复原来“只有先成功，才调用另一套算法”的分支错误。物理中层转动
  产生的核心奇偶差用真实 `M` 前缀修复，并保留该步用于完整回放。
- 26 次求解回放检查通过：9 份百步绑块重建，二阶 3 份四十步状态各用
  两种快速预算、6 份短状态，五阶 3 份中层状态和 2 份随机录入。
  五阶随机案例强制首条路线失败后仍成功。另检查取消与非法颜色，共 29 项。
  另通过实际求解服务分别检查二阶、五阶和 BiCube，共计 32 项针对性检查。
  这些是自动重建手动输入的模型检查，没有新增手机或真实控件验收。

## 已增加的状态算法

| 型号 | 当前算法 | 验收依据 |
|---|---|---|
| Fused | 固定三阶中心方向后，在合法 L/D/B 转动群中求解 | 40 步重新录入、整体朝向、真实录入控件 |
| AI 4×4 | 穷举 70 个无色连块布局，先回到基准布局，再解配色 | 40/100 步，共 24 份手动重建状态 |
| Burr 4×4 | 穷举 182070 个无色布局，验证 1294884 条有向边的闭合公式 | 40/100 步，共 24 份回归状态；另有 48 份压力案例 |
| 4×4×2 | 两组角方向共同描述实体形状；查表恢复形状，再解配色 | 2421009 个可达形状，形状阶段至多 11 步；16 份六视图重建 |
| Pentacle | 六个自由圆盘先按 72° 对称性归一化，再解有限配色群 | 1221 条表内公式逐条实体回放；12 份任意圆盘角度重建，2 份真实界面录入 |
| Circle 2、Crazy 八大行星 | 各自实际转动群的稳定子链，处理相同颜色块的不可区分性 | 9 型号共 225 份无历史状态，9 份真实界面录入 |
| Mixup / Plus 八型号 | 恢复真实形状和配对，再接三阶/四阶；Plus 增加局部内棱倾斜修复 | 同一批八份可见面片录入全部通过；保留既有失败回归 |

AI/Burr 的布局图穷举包含所有整体朝向。离线构建器对所有图边的
Schreier 闭合变换做群成员检查，并独立回放导出的公式。
4×4×2 的基准布局群达到四个八块轨道所允许的完整奇偶约束上界。
Pentacle 的圆盘可连续转动；先消去连续相位，余下的 72° 圆盘转动和
对齐后的 90° 整层转动组成有限群。求解不读取原始打乱路径。

## Mixup 的变化

Plus 333/334/344 使用同一个合法转动群重新编制较短公式，保留原有
内棱公式目录。局部倾斜修复只匹配受影响的内棱位置，每一步仍须通过
完整模型的合法性检查，并且必须减少倾斜块数才会采用。

保存的八份案例包含 49–110 次打乱转动。一次独立顺序测试中，Plus
333/334/344/444 分别为 367/797/984/954 步、约 3.5/5.9/14.7/15.3 秒。
时间取决于电脑负载；这是这些案例的结果，不是任意输入的时间保证。

## 搜索限额更新

- Tangram Extreme 已用离线形状距离表替换原有截断搜索；没有固定的
  60 层、每桶 500 条候选、50 万节点或默认 20 秒退出条件。
- Tangram／Extreme 的完整转动群和回形稳定子已独立核对。Extreme 的
  按 pCubes 切距与中层 60° 带动棱轴的机制重建后，形状轨道为 6311112192，
  包含两个转轴相位。现有配色公式表覆盖完整回形稳定子；通过相位零固定动作群、
  精确集合稳定子搜索及两相位双射核对，并非从随机测试推断。
- Camouflage 先走快速搜索，再继续渐增代价完整搜索。Mixup 快速降阶
  达到限额后，接上包含所有合法连续宽层转动的实体完整搜索。
- AI/Burr、4×4×2、Pentacle、Circle 2／Crazy 和 Tangram 的有限群配色匹配
  不再按默认秒数或节点数自动中止；缓存达到容量后停止增加缓存，继续探索。
- 这些搜索均可取消；取消保留原输入。显式指定计算预算的开发工具仍可限时。
  录入匹配的独立预算没有改动。

完整搜索不保证短时间完成。Mixup 与 Camouflage 的深层实体后备搜索仍可能
非常慢，当前后备路线的实际验收以浅层案例为主；深层保存案例通过的是
较快的分阶段路线。理论覆盖当前有限模型，也不等于已经验证所有实物结构
或手机性能。公式不保证最短。详见 `docs/search-limit-removal.md`。

新增资源是随包读取的小型离线数据，不在手机端生成，不需要联网。
本次没有生成 APK 或 Windows 发布包，也没有验证真机性能。
