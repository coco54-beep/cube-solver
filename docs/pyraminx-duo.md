# Pyraminx Duo（双子金字塔）

入口：首页 → 特殊异形 → 双子金字塔 · Pyraminx Duo。

普通单色中心版本，4个三色角块、4个单色面中心，共8块、16个可录入色面。四根角轴均转120°；每次转动一个角和相邻三个面中心，其他三个角保持位置和方向。单色中心的朝向不作额外限制。不支持带图案方向的中心版本。

模型、触控、随机打乱、逐面录入、求解回放和会话保存共用同一组实体块及转动置换。中心可以移动，录入时不预置中心颜色。外壳采用平直理想几何，中心三角比例近似，未复刻塑料圆角。

## 最短解

`tools/build_pyraminx_duo.py` 从还原态作广度优先搜索，生成324种合法颜色状态的专用表 `solver/data/pyraminx_duo.bin`，带几何指纹。每次120°或其逆向各计一步，最短距离分布：0步1种、1步8种、2步48种、3步188种、4步79种。

运行时直接查询，拒绝不在表中的录入状态；解法返回前从输入状态完整回放。生成器也逐条回放生成公式。无需手机现场搜索或依赖打乱历史。

## 典型情况教程

- 8种“一个角和相邻三个中心同步错位”的单步情况。
- 3种“四角已齐，面中心两两交换”的四步情况。

每例说明识别条件、拿法和公式，并从待还原状态播放到完成。教程不会修改用户录入。
