# 1.2.20

包含主分支中已提交、尚未发布为 GitHub Release 的 1.2.19 更新，以及以下界面调整：

- 金字塔、斜转、五魔方、魔塔的还原播放界面参照普通魔方，统一动作提示、进度条、播放按钮、速度和停留设置。
- 还原播放界面遵循简洁／高级设置：简洁模式保留上一步、播放、下一步和返回；高级模式增加首步、末步和恢复视角。
- 粽子魔方的简洁播放模式固定视角，高级播放模式允许拖动观察。
- 异形魔方录入界面保持原来的图标、选色和形状卡片布局，不受简洁／高级设置影响。
- 修正异形录入页返回时的交互状态复位。

本次仅进行打包，未新增或运行测试；此前界面修改已进行桌面截图预览，尚未进行真机验证。
