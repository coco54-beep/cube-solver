# 长方体与迷彩录入：按实物观察重做

状态：六视图已接入正式入口，替换可变形长方体和迷彩的摆块流程。四款延伸机构与状态求解已接入，见 `docs/cuboid-state-solvers.md`。以下保留设计约束；逐层补录仍是后续方案。

## 已接入的软件流程

- 新建可变形长方体或迷彩时直接进入 `CuboidSixViewScreen`，不再进入摆块弹窗。
- 前、右、后、左、上、下各自记录可见颜色、面片切缝、黑色塑料、空位和未录；拖框将多个采样格合为同一面片。
- 默认自动匹配局部高度，必要时在选中区域指定从外向内的高度层。六视图共用空间中心和方向约定。
- `SixViewDraft` 独立于可播放状态；后台匹配现有型号的实体块、朝向、占位和遮挡。冲突、歧义、搜索预算耗尽分别提示，不会把未录处补为还原颜色。
- 同形同色且机构等价的内部身份由程序匹配，不向用户展示内部编号。只有唯一匹配后才应用到拧动/求解状态。
- 保持原形的标准 3×3×2、2×2×3、3×3×4 继续使用原有逐面颜色输入。
- 18 个软件打乱状态完成观察→匹配的往返检查，另检查未录、矛盾、超时和取消。7 项桌面界面流程检查通过。软件状态自检不替代独立实物验证。
- 4×4×6 已使用四阶核心和独立外层延伸，求解后检查每一步合法性及完整回放；仍需独立实物对照。

## 上一版为什么仍然难用

`CuboidEntryPopup` 先让用户选择内部 piece 编号，再遍历该块的 frame 轨道位置和方向。用户必须知道块的原身份、其相对机构核心的位置和朝向，才能完成录入。实物没有这些编号，变形后也看不到核心。

`CuboidEntry` 从当前模型的颜色和块身份制作卡片；新建空白状态会以还原配色替代未知颜色。它能够编辑模型已有的块，却没有实现“根据用户看到的颜色和外形辨认块”的逆过程。同色同形块还暴露成不同编号。

此外，外观尺寸、内部机构、可见贴纸不能全部用一个 n 阶网格表示。旧 `cuboid_446` 以 6 阶网格分组，现已按四阶核心和可分离外层延伸重做；六视图的 6×6 仍仅是采样范围。

## 用户只录观察结果

### 六视图为主，逐层作为补充

根据后续讨论，主入口采用六视图。4×4×6 等型号的观察框可使用足够大的 6×6 范围，用户只标实物占据的部分，并不意味着每面必须录 36 个块。物理块跨多个单元时应合并记录，不能把采样单元当成独立实体块。

六视图分别记录从六个方向看见的外形、切缝和颜色，不能直接当成 216 个体素的完整赋值。轮廓交集只能约束外形；凹陷、被遮挡贴纸与连接关系仍可能有歧义。程序只针对有歧义的局部请求高度关系或补看侧面，不要求所有状态一律录六层。

逐层模式作为可选补充：显示某个物理高度的占位，共用所有层的前后左右参照。一个实体块跨层出现时使用同一块标识；其内部截面不能被当作额外贴纸面。每个块的六方向使用颜色、无贴纸塑料、未知三类独立状态。

### 保持原形的长方体

主界面只显示一个正对的矩形面，逐面点色。例如 3×3×2 的两个大面为 3×3，四个侧面为 3×2。持握方向有常驻的顶部标记；左右切面只翻整体。

后续用户明确要求：不能变形的型号继续沿用原来的颜色输入，不迁移到新六视图或逐层编辑器。标准 3×3×2、2×2×3、3×3×4 已在 `FIXED_SHAPE_KINDS` 中明确分类；录入页隐藏摆块入口，保留原有填色与切面操作。变形能力按型号判断，不根据当前是否恰好处于原形判断。

用户不选择块、不摆三维位置。程序通过相邻面颜色组合、型号的位置轨道和方向限制匹配物理块。同色同形块保留等价候选，不要求选择隐藏编号。

以标准 3×3×2、2×2×3、3×3×4 作为首批独立核对对象；不能把整族都当作固定形状。

### 已变形的长方体

用户仍从当前观察面开始：先点实物对应的位置，再选择此处可见的面片形状和颜色。该位置的候选只显示在原地，不用全局“位置 1/24”轮换。

默认依次记录正、右、后、左、上、下的观察结果。朝向与已录相邻面有共同参照边。三维预览供对照，不承担精确点击和自由拼装。

程序用这些观察筛选允许的物理块位置与朝向。未确定时保留多个候选，并定位下一处需要补录的侧色或邻接关系。不得凭一张轮廓图生成唯一内部状态。

### 迷彩

在上述面片录入上增加局部高度关系：与邻块齐平、凸出、凹进。具体可选宽度和高度来自该型号实际几何，不让用户输入坐标、角度或猜核心位置。

每次选中一个位置时，同时显示该处正面和小侧视图；高度操作改变侧视图。大方块、小方块、长方块、黑色塑料面、未知区域分别记录。未知不能自动视作黑色或还原颜色。

一个物理块跨观察面的信息必须关联。记录了正面的长方形，不代表该块的顶面、侧面也已确认。被遮挡的区域应允许“暂时看不到”，由其他观察约束或后续补录确定。

## 实现分层

1. **型号机制**：每款独立声明核心、延伸件/绑块、贴纸所在面、真实尺寸和切层限制。未核对的型号不自动套用通用模型。
2. **观察草稿**：保存观察方向、局部参照、二维面片边界、颜色/塑料/未知、已知高度关系、跨面关联；与可播放状态分开。
3. **候选匹配**：程序匹配块身份和方向，保留等价块与歧义；未录信息不补成还原态。整体坐标原点由程序对齐。
4. **反馈**：重叠、颜色组合冲突、缺少侧色在对应位置提示；可修改、撤销。搜索时间不足与确定矛盾使用不同提示。
5. **提交**：只有外形、颜色、物理块归属和模型兼容性达到要求才生成可播放状态。结构一致不等于证明可解，不能把计数检查称为完整可解性验证。
