# 六角星金字塔：独立圆鼓四面体模型接入

公开标识 `lanlan_hexagram`，显示“六角星金字塔 · 几何模型”，放现有金字塔分类。保留四个角，与无角的蓝蓝三叶草金字塔分开。

- 外壳由正四面体四个顶点为球心、棱长为半径的四球交集独立生成，以闭合弦面网格近似曲面。模型保留四面体十二种正旋转对称，网格构造线不变成额外输入小片。
- 自身截面参数为 0.49；独立裁出 35 个材料实体、64 个色面，每面 16 片：4 个三色角、18 个双色块、12 个单色块和带 4 个中央面的固定核心。它与双鱼座的 60 色面、6 色配色、块类型分布及求解指纹不同。
- 十二根偏轴，约 67.115°、146.443°；受阻时拒绝整步。28 个闭合工具在本模型上重新逐步验证，没有只复用双鱼座的结果。独立颜色群阶为 4837294080，132 条运输记录逐条回放，数据 2793 字节。
- 三个种子各 30／100 个闭合工具并加部分转动，6 个姿态重录和 6 个仅填色重录案例均独立解出，最初姿态重录解法 107～207 步。不会读取打乱历史。
- 公共录入、填色、姿态草稿、拧动、打乱、撤销、取消、失败保留、保存及回放已接通。固定核心误转在输入页指出中央字段并保持输入，不跳到求解页等待超时。
- 原创课程包括两类偏轴、闭合复形工具及仅循环三个双色块的完整工具；实际作用、三次恢复和起始状态均有回放验证。
- 与双鱼座、已有照片型号和教学相关回归共 281 项通过；补充固定核心错误处理后的相关检查共 68 项通过，测试有重叠。800×600 和 390×844 原生界面均通过姿态测量重录、连续填色、拧动撤销、求解和 200 步回放。
- 新增曲面网格压缩数据 13565 字节，重建时 SciPy 只用于离线生成；手机运行时不需要 SciPy、SymPy 或生成大表。
- 补齐 Windows 资源清单中的 `cube/data`，并审核安卓资源选择，避免以后打包遗漏曲面网格。最终模型及资源相关 54 项通过；本轮仅检查资源清单，没有生成安装包。
