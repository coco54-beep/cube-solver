# 录入、拧动、还原页按键规则

## 录入

| 按键 | 行为 |
| --- | --- |
| 随机打乱 | 先生成合法布局，再替换录入；不增加确认弹窗，可撤销。 |
| 初始值 | 将当前型号设为已还原并已录入；可撤销，不改变镜头锁定、跟随设置。 |
| 清空 | 普通与多数按块录入页先确认；Mixup、Pentacle 直接清空，六视图直接清空当前面。均可撤销，不更换型号、阶数或配色。 |
| 撤销、重做 | 恢复录入数据并清除过期校验；支持重做的页面，新编辑会清空旧重做分支。 |
| 校验 | 检查当前录入并标出问题，不自动打乱或求解。 |
| 求解 | 使用当前录入；求解期间不允许同时改录入或再次启动求解。 |
| 换面 | 当前翻面结束后才能再次换面；翻面期间不并发执行随机、清空、初始值等操作。 |
| 返回、切页 | 保留当前输入；同一布局再次显示时不清空撤销记录。 |

普通魔方的随机、公式打乱、初始值和清空均按一次完整编辑保存，可一次撤销。
粽子、镜面和其他按块录入的魔方保留其结构与预置中心规则。

## 拧动

| 按键 | 行为 |
| --- | --- |
| 正转、反转、拖动拧层 | 动画或镜头跟随尚未结束时不并发启动新转动。 |
| 撤销、重做 | 回放逆动作或原动作；新拧动会清空旧重做分支。 |
| 单层、宽层 | 拧动期间不切换，避免操作模式与当前动作混淆。 |
| 返回 | 保存拧动后的状态回到录入；转动未完成时暂不返回。 |

普通魔方、颜色异形和粽子/镜面类返回录入时，保留原录入的撤销历史，并记录本次修改。

## 还原播放

| 按键 | 行为 |
| --- | --- |
| 播放、暂停 | 暂停取消后续自动走步；已经开始的一步正常结束。 |
| 上一步、下一步 | 先暂停自动播放，再手动走步，不在手动操作后自动续播。 |
| 回到开头、跳到结尾、返回录入 | 打开确认框时暂停；取消后保持暂停；确认后执行跳转或返回。 |
| 进度条 | 停止自动播放，按目标步数重建显示状态。 |
| 速度、停留 | 调整播放节奏，不改变录入、解法或当前步骤。 |
| 复位视角 | 只恢复观察角度，不等同于将魔方恢复到已还原状态。 |

## 镜头设置

锁定视角会将跟随设为 0；开启跟随会解除锁定。手动解锁不会自动开启跟随。
页面切换保留设置，复位视角不更改设置。

## 求解中

普通魔方、粽子、镜面、各类多面体异形和 SQ1 统一进入求解页，显示模型、当前处理阶段、进度条和文字“取消”按钮。

- 有进度回调时显示该阶段进度；没有进度时保持准备中，不编造总进度。
- 取消立即返回原录入页，保留输入和撤销历史；后台未及时退出的旧任务不得改变新页面。
- 成功进入对应的还原播放器；失败返回原录入页，在页内显示“求解未完成”，保留输入，不再弹出错误窗口。
- 取消、离开页面后，旧任务的进度和结果一律忽略。

## 连点、旧卡片与弹窗

- 镜头动画、拧层或后台任务期间，录入编辑与换面不得同时执行。
- 换位置或重建候选卡片后，上一批卡片延迟到达的点击不得修改新位置。
- 已离开页面的按住按钮，松开时不触发旧页面操作；原页面的确认弹窗随切页关闭。
- 求解请求重复到达时保留当前任务，取消后重新求解使用新请求。
- 多颜色配色页采用可滚动的多行色块；重建配色页后，旧色块不能选择新页面的无效下标。

## 统一录入任务和反馈（2026-10-25）

- 输入校验失败留在原页，状态区域按原因显示“录入不完整”“状态不合法”“搜索超时或达到限额”“程序异常”，保留原有错误位置高亮。匹配结果同样使用这四类；取消单独显示。
- 求解准备失败不跳页；已经开始计算后的失败返回来源页。两者都保留当前录入，不把求解器内部问题直接判为输入非法。返回页的失败提示在该页恢复完成后显示，避免被“恢复布局”文字覆盖。
- 长提示自动换行并扩展状态区域；恢复普通进度文字时收回高度。
- 后台任务由 `EntryTaskState` 统一管理：空闲、工作中、打乱、匹配、准备求解和求解。任务身份与页面是否活动共同决定动作按钮是否锁定；取消／返回保持可用。原来的镜头和拧层动画保护继续生效。
- 打乱按钮不再定时轮询 `_job`。异步任务开始／结束的状态事件直接锁定／解锁；同步打乱在当前回调期间锁定。旧 `_job` 属性只作兼容入口，实际任务身份由状态对象持有。
- 离开录入页立即取消旧任务的应用资格，动作按钮不会在切屏过程中短暂解锁。回到该页再恢复编辑；子按钮原有的“无撤销记录”等禁用条件继续保留。
- 离开求解页从切屏动画开始时就使任务失效。不可及时退出的旧后台计算仍可能结束，但其结果和进度不会改变新页面。
- 重复的进入事件不会多开求解线程；重复求解请求不会覆盖正在处理的请求。取消待启动任务后，迟到的进入事件也不会启动它。

## 手机简洁模式和恢复操作

- 共用动作栏及普通魔方简洁录入栏在窄屏保留“撤销、还原、更多”；打乱、清空、填入还原态、拧动及配色等放入可滚动菜单。菜单继续沿用原有动作及禁用条件，切页关闭，旧回调失效。普通魔方高级面板保留原有布局。
- Mixup 选择颜色后保持连续上色，再点同色不会退出上色；“连续上色／选块调方向”按钮明确切换模式。选中块保留高亮；组合、方向和确认仍按该型号的实际结构处理。
- 失败状态下显示“定位问题、重试、继续编辑”。已知错误位置可以逐个定位，定位不修改输入；普通魔方的定位圆点在重绘后仍保留。只有超时和程序异常允许直接重试，缺失或非法状态应先修改输入。
- 颜色总数、整体奇偶等约束未必能确定唯一错误块；无法定位时明确提示逐面核对，并禁用定位按钮，避免虚构错误位置。
- 求解中取消、返回、换页后的旧结果仍不得改变录入。重复状态的缓存命中也必须重新合法回放后才能使用。
