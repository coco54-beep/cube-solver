# Dogic 十二色／二十色：共用同一实体切割

按用户要求，两版共用相同的二十面体外壳、80 个实体三角块、十二根转轴、每轴两个转层及 72° 转动。二十色版以每个完整三角面一种颜色为还原目标，共二十种颜色，每色四片。

原实现已共享物理块数，但在十二色版的三色中央块中，把三条配色边界也画成了黑色切缝，灰模看起来像额外拆块。本轮改成单一 `dogic_physical_layout()` 生成实体；渲染以实体外轮廓画缝，不把中央三色区之间的边界当作机械切割。十二色版仍能分别录入三个色区，二十色版中央整片一次填色。

- 两版依然分别有 120／80 个可录入色区，这不是物理块数差异；二者都只有 80 个实体，中央三色区始终属于同一个完整三角块。
- 现有模型面序、动作置换、保存格式及求解表指纹保持一致，旧录入和回放无需迁移，也没有增加新表。
- 211 项相关检查通过：`reports/dogic-colourways-final.xml`。包含实体和转层逐项对应、每个动作五次恢复、20 个完整单色面、中央三色块不可拆、既有表和保存兼容，以及两版各 30／100 步重录求解和完整回放。
- `visible/results.json`：800×600 与 390×844 各验证两版录入、连续上色、撤销、拧动、求解和回放，四例通过。十二色版各 247 步，二十色版各 272 步。仅为桌面图形环境验证，未做安卓真机测试。
- `comparison/comparison.json`：使用同一镜头和尺寸导出的两张灰模，RGB 像素完全一致；上色图保留不同配色。相关缩略图已更新，没有打包。

可复跑 `tools/audit_dogic_colourways.py` 和 `tools/preview_dogic_colourways.py`。
