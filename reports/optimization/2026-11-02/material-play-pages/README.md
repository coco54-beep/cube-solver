# 七款魔方取消手动录入

按用户要求，以下七款从目录进入时直接显示完整配色的初始魔方：曲线直升机（魔蝶·球切模型）、蓝蓝Crazy Comet、双子星、太阳二号、六角星金字塔、花瓣魔方（魔花）、蝶恋花。

- 删除页面中的颜色栏、逐面填色导航、配色设置、“调整形状”入口和录入进度；模型点击不再上色。
- 更多菜单不再提供清空录入，原“填入还原态”改为“重置魔方”。保留打乱、拧动、撤销、求解和教学。
- 从拧动页返回时保留刚才的状态，重置后仍可撤销。旧空白录入存档恢复为完整初始模型。
- 精简控件后重新计算布局，使横屏模型与操作面板分开；竖屏上下排列。
- 六视图型号、普通颜色录入型号和物理引擎接口保持原有流程。七款内部屏幕名沿用旧名，避免打断回放、求解返回和存档路由。

验证：`tests/test_material_play_pages.py` 与 `tests/test_entry_workflow.py` 共61项通过。覆盖七款初始化、无录入入口、模型点击不改色、实际转动及返回、重置与撤销、求解提交、打乱成功/失败和旧空白状态恢复，以及共享取消/失败流程。

`tools/audit_material_play_pages.py` 从实际目录进入七款，在800×600和390×844下检查14个页面与更多菜单，全部通过。检查横竖屏模型与操作区不重叠；截图和记录见本目录PNG及 `ui-results.json`。

未打包，未进行安卓真机测试。旧开发工具中按可见观测重新构造状态的实验不代表当前App仍提供手动录入入口。
