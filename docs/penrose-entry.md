# 彭罗斯选块录入

## 修复的问题

旧入口将相同外观颜色拆成六个虚拟颜色，填色时又保留原有块身份和外壳朝向。因此，从空白页输入实物颜色不会生成对应的打乱外形，后续提交也可能把错误外壳带入拧动与求解。

## 当前流程

- 二、三、四阶统一在原三维模型上点位置，然后选择整块的实物形状与配色；不再显示直接涂色的色条、取色或整面填色按钮，单格填色和拖动涂色也不会修改彭罗斯。
- 二阶选择角块，三个面同步录入；三阶、四阶的角块、棱块／翼棱和中心都采用选块方式。四阶每个翼棱分别点选，不把两块翼棱当成一个整体。
- 卡片使用真实圆弧／平面几何及完整配色。同一块的不同朝向合并，由旋转按钮切换：角块三种方向、双色棱两种方向；无可见方向变化的中心不启用旋转。
- 角块最多八组、棱块六组、中心三组，四列显示，每页最多八项。相邻面已经录过的整块，点回后可以继续更换或旋转；所有关联面同步更新，其他块不变。
- 选卡后，根据完整可见配色重建圆弧、平面和朝向；未录入的块保持中性网格占位，不假装是已确定的还原外壳。
- 当前三款外壳中，同一槽位、同一可见颜色排列的候选具有相同的实际外形。重复的内部身份不显示为额外颜色选项。
- 整块卡片直接使用渲染器中的真实几何，不使用方块线稿代替圆弧。
  选卡后的形状由整块完整配色唯一表达，继续沿用原有三色保存、撤销、重做与匹配流程；
  没有另存一套可能与颜色冲突的形状标签。
- 进入拧动或求解前，还要匹配完整块库存和机械约束：角朝向和；三阶固定中心的整体朝向、棱朝向和、角棱奇偶；四阶翼块合法位置与角中心奇偶。三阶中心不能各自任意换面。
- 匹配后的六个虚拟颜色仅供现有普通阶数求解器使用；求解、回放保留重建的真实外壳。
- 拧动后返回、撤销和重做均从三色观察重新生成外形。彭罗斯草稿按型号独立保存，不与普通魔方同阶草稿混用。
- 已还原的三色状态优先选择还原标签，避免重置后产生多余的虚拟打乱。
- 读取旧版状态时，先核对贴纸是否真正属于当前块及朝向；排除“只改颜色、外壳未动”的旧数据，不再直接复用其错误外形。
