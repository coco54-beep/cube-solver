# 十四面直升机：合法混转、形变打乱与独立状态还原

2026-11-02，已接入源码，未打包。目录位置不变：转棱系列 → 十二轴十四面体。

## 实现

- 新建模型使用 `cube.edge_jumbling.Helicopter14Cube`。保留原十四面外壳的平面、切深和32块外观分区，补齐45个完整材料区，包括没有颜色的内部材料；没有把普通直升机立方外壳直接换名字。
- 十二条原棱轴可半转180°；约70.528779°／109.471221°准备后可以解锁重叠转层并产生形变。切面必须完整包含或避开每一实体，跨块动作拒绝执行。内外材料在同一旋转中运动，所有颜色保留。
- 八个截角是八个不同的物理面、同一种金色，不增加金色面的转轴。六种主色各4片，金色8片；几何法向仍保留14个面。
- 除十二个常规半转，验证了24个五步闭合混转工具：两端准备、目标棱半转、逆序收回。每个工具均由完整材料检查，末态检查全部45实体回到对应的实体槽位；不是只验证画面色片。
- 随机打乱交错使用常规半转和完整混转，再加一个合法准备动作形成非标准外形。内部不保存还原用的打乱历史或逆序答案。
- 新的独立状态求解器先复形，再完成24个彩色三角片。八片金色无需区分隐藏编号。颜色求解的轨道三循环及运输覆盖经离线验证，全部返回动作再通过原生整块规则回放。
- 金色同色异面的计数修正同步到共用录入校验和 `MaterialSolver`：比较型号初始配色，而非把物理面编号误当颜色编号。没有将面6～13当作八种颜色。
- 接入新建工厂、共享模拟／拧动页面、后台求解、JSON检查点、回放渲染、重置、撤销和教学。新入口不提供手工摆块或填色；旧 `PolyhedralPuzzle` 固定槽位存档保持原类型，不强制解释成完整材料状态。重新从目录进入型号即可使用新实现。
