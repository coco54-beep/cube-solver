# 其他魔方是否存在同色配对或混转覆盖遗漏

2026-11-02。用户问其他型号是否存在双子星相似的问题。本轮为只读机构和入口审计，新增检查脚本及记录，未修改各型号的动作、打乱、求解或目录。

## 已确认的问题

### 普通直升机、四叶草：打乱主体和配色求解缺少混转覆盖

`cube.edge_jumbling.scrambled` 的这两款在主体阶段仅随机常规180°，随后追加少量形变。该形变后缀不等于已经覆盖完整闭合混转后的配色轨道。

在当前完整材料几何中，下面的动作全部合法，末态闭合，而且逆序回放恢复全部材料：

1. 轴1准备 +70.528779°；
2. 轴6准备 +70.528779°；
3. 轴0半转180°；
4. 轴6收回 -70.528779°；
5. 轴1收回 -70.528779°。

该动作将两个色面带出普通半转所保持的分组。两个型号各用三个种子，先做20次随机常规半转，再执行上述工具，当前 `solver.edge_jumbling.solve` 均立即抛出“块配色或位置不可能”的错误，尚未进入超时搜索。复现见 `witness-solve.json`。这说明软件自身接受的合法闭合动作，其结果未被配色求解器覆盖。

它与双子星原先“两个独立色面始终同色”并非完全同一种表现，但属于相似的打乱／求解子群覆盖不足。不能只加打乱步数，需把完整混转与其求解同步补齐。几何合法性结论不代表测量过实物内轨。

### 五款旧存档：仍会留在旧固定槽位打乱入口

普通直升机、Rua、四叶草、紫荆花、十四面直升机，恢复旧 `PolyhedralPuzzle` 检查点后仍保持该类型，没有完整材料的 `frames`。其旧 `PolyhedralScreen.randomize` 克隆该固定槽位状态并调用普通打乱，不会经过目录中新建完整材料模型的入口。

`legacy-entry-paths.json` 核对了五款旧检查点解码类型和新建类型。新建目录入口有完整机构，不等于恢复旧存档后点打乱也使用新机构。双子星在上一轮已修正这个分流，其他五款本轮尚未修改。

## 本轮未检出相同配对限制的范围

`material-models.json` 覆盖12款当前公开完整材料模型：普通直升机、Rua、四叶草、紫荆花、十四面直升机、曲线直升机、花瓣、蝶恋花、太阳二号、蓝蓝Crazy Comet、六角星金字塔、新双子星。

对各自当前闭合动作，计算单色面独立实体之间保持颜色一致的等变映射，包括跨两个轨道及同轨道内两种情况。排除全轨道本就只有一种颜色的区域和同一实体多面联动，避免把金色截角、固定中心或完整块的正常结构当缺陷。上述12款当前动作中均未检出与旧双子星相同的强制同色配对。

另检查8种Crazy大行星的声明动作和固定圈设定，见 `crazy-planets.json`，未检出上述独立实体配对关系。固定圈和固定中心自身不动不属于本结论中的漏洞。

花瓣和紫荆花目前也以普通闭合转动为随机主体，形变主要在末尾增加，存在混转深度偏浅的风险；本轮有限五步工具探测没有找到它们的新跨轨道证据，不能就此宣布动作完整，也不能称为已经复现相同错误。

Mixup、SQ、迷彩、圆圈二阶等状态相关机构，以及目录其余型号，本轮未重新做全状态机构审计。不能把这20款的检查外推到全部目录。

## 可重复检查

`tools/audit_scramble_colour_coupling.py` 读取12款当前模型及闭合动作，输出普通分组、同色配对和有限完整材料五步探测。未执行任何 pCubes 嵌入脚本；无记录命中只表示此探测没有发现，不是机构完备证明。

修正优先级：普通直升机、四叶草的完整混转与求解覆盖；随后修复五款旧存档的打乱入口；再补花瓣、紫荆花的深层混转覆盖验证。
