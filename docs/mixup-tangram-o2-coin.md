# 新增型号：实现范围与待完成工作

本轮是初版接入，不能据此宣称十三种实物均已完整支持。

Mixup / Tangram 的正式录入已改为逐面轮廓观察，支持先选区域分块数，再录形状、方向与颜色；见 [逐面观察录入](articulated-observation-entry.md)。下文早期的逐实体编号摆放流程已由新入口替代。

## 输入与资源限制

- Mixup/Tangram 记录每个实体的姿态，不用贴纸颜色代替完整形状。
- 点实体或左右换块，主视图显示候选位置，小视图显示选中块；轴向箭头调整姿态，确认时检查是否与已确认块相交。
- 手动确认清除旧打乱记录；不会用不再对应输入的记录冒充求解。
- 手动搜索最多 8 秒、10000 个递归节点、6 层，超限明确提示。
- 反向打乱路径也必须合法回放且完全复原，才返回为解。
- 草稿保存实体姿态、已确认集合、选中实体和候选姿态，回放检查点保存完整姿态。

## 待完成

2. Tangram 切割比例由三角柱结构及参考外观推导，需要核对实物转动约束。
3. Mixup 的深层手动形状及配对状态、Tangram 的深层手动状态尚无完整构造求解器。
4. Pentacle 根据用户确认的“圆盘自由转，五角星棱连成直线才可拧层”建立几何判定。初版用圆内五条弦切割，并对外壳按核心网格分组；具体外观比例仍需要实物核对。没有用固定72°圆盘或普通三阶替代。
5. 生成了 13 款目录缩略图并完成 Python 语法编译；未新增或运行自动化测试，未手机实测，未生成 APK。

## Mixup 打乱与分阶段还原（2026-10-21）

- 修正黑色补面被当成实心体积、误拦45°后交叉转动的问题；可见面相交仍会被拒绝。内部机芯和连续转动路径仍未声称已完全建模。
- 移除固定槽位重新赋形、缺色时用第一种颜色填充的三阶显示方式，保留每个原始实体的面、颜色和姿态。
- 打乱先产生颜色状态，再加入45°中层转动和交叉轴外层转动；三阶普通/Plus的最终状态必须同时有中心进入棱方向、棱进入中心方向，不能以只有倾斜姿态冒充互换。界面显示互换数量。
- 所有打乱尝试共用一个6秒期限。未能生成满足要求的状态时保留原输入，并提示重试。
- 形状阶段检查实际表面几何能否回到初始切割，以及同一虚拟格内各片颜色是否一致；三阶投影还检查普通三阶可解性。
- 3×3×3以及配对后的3×3×4、3×4×4接三阶求解；4×4×4接四阶求解，正确重建中心块的home信息。
- 打乱记录只用于帮助到达形状/配对边界，剩余颜色交给对应求解器；不再把全部记录倒放冒充完整分阶段解法。
- 普通求解器的动作逐条映射回真实Mixup，再检查完整的形状及颜色终态；回放显示“恢复形状／按三阶或四阶还原颜色”。
- 做过一次三阶和一次四阶实际功能诊断：分别返回10+20步、10+190步并通过求解器内的实际Mixup终态检查。不是完整回归，也没有手机实测。
- 固定槽位模型的旧非平凡piece_ids草稿与新版实体姿态不兼容，不把它当作有效新状态载入；此类草稿需重新录入。

## Mixup 334 / 344 / 444 转层限制修正

- 转层不再只靠块中心点和最终姿态判定。提交任何角度前，检查每个完整块的全部原始彩色面是否跨过目标层的两条边界；四层中间的零切面也参与检查。
- 跨层块存在时拒绝该次转动，即使转到90°或180°后的外观似乎可行，也不能跳过起始位置的卡块限制。拒绝发生在状态、操作记录和动画修改之前。
- 同时检查被选中的块是否完整位于目标层、未选中的块是否错误留在目标层内。各块沿转轴的坐标在整个转动过程中保持不变，因此这项切层检查约束整个转动过程，而非只采样终点。
- 按钮、手势、随机打乱和求解回放共用同一判定；普通及Plus四种尺寸均接入，没有一律禁用45°转动。
- 检查依据可见刚性面板；黑色显示补面不作为实物机芯体积。尚未手机实测或完成实物逐动作核对，未生成APK。

## Mixup 错层后的块身显示修正

- 将彩色面后的浅背板改为向转轴核心收拢的封闭块身，补齐侧壁和背面，减少棱心互换后看起来像缺块的空洞。
- 取消渲染阶段对每张块身面的重复缩边；贴纸保留自身边框，块身的侧壁、背面与正面边界相接。
- 块身仅用于显示，随原始块一起转动，不参与转层合法性和求解判定，不给原本无贴纸的背面补造颜色。
- 已完成语法编译；尚未实机确认用户看到的缺块情况全部消失。

## 打乱偶发超时处理

- Mixup 在实际合法的45°中层转动形成错层后立即保存候选，再尝试交叉轴外层、颜色打乱和形状深度；不再等待交叉转动成功后才保存。三阶普通／Plus仍检查棱心双向互换。
- 移除基础阶段至少20步才允许结束的条件，按预算比例给后续错层搜索留时间。内部时间到达使用单独的异常类型，避免与物理卡块混淆。
- 建立候选后的任一阶段耗尽预算，返回已保存的有效候选；只有尚未生成有效候选才报失败。不会把还原态或仅有普通转动的状态当作错层打乱返回。
- 短于20步的结果在新录入页明确标为浅打乱，可再次生成。用户主动取消始终停止，不会套用旧候选。
- Mixup 的整块切平面检查已经让移动、静止面片沿转轴坐标分离；旋转保持该坐标，因此去掉同一动作上重复的二次方端点面片比较。切层／角度／姿态限制继续生效；手动摆块保留面片相交检查，Tangram保留实体体积相交检查。
- 完成语法编译；本轮未运行自动化测试或实机计时，未打包APK，未宣称任意设备和任意预算下都能生成足够深的打乱。

## Mixup 打乱深度调整

- 基础颜色阶段由固定20步调整为32～64步目标，并为形状阶段预留时间；四层轴越多、Plus分块越多，目标越高。优先尝试内层，334/344卡住的候选仍拒绝，改试其他合法层。
- 错层阶段由最多8步调整为40～72步目标，增加内层45°、90°、135°及外层不同角度的候选，优先换轴，不连续操作同一层，不接受该阶段已访问的完全相同状态。
- 按非直角姿态块数量、姿态种类、离开原位置的块数量择优保存；后续随机动作若让状态更规整，不覆盖之前更丰富的候选。三阶仍要求同时有中心和棱互换。
- 目标步数受同一6秒期限和实际合法转动限制，不承诺每次走满；超出后续探索预算返回已有有效候选。启发式指标不等于最短还原距离，也不代表均匀随机抽样。
- 保留完整合法动作记录供形状阶段使用；没有放宽转动约束。完成语法编译，未运行自动化测试或手机实测，未更新APK。

## Pentacle 操作

- 普通色板点选用于填色；当前面圆盘可在 -180° 到 180° 范围自由预览，精度 0.1°，再点“转动圆盘”提交。
- “对齐当前层”求四个相邻圆盘距离最近的切线对齐角度；此操作只调整圆盘，之后仍由用户决定是否拧层。
- 拧动页有“圆盘”和“整层”两个选项；圆盘按钮以1°微调，拖动圆盘根据起止触点计算实际转角（0.1°精度），整层按90°操作。
- 对整层逐块检查切平面是否穿过一个完整块，穿过时拒绝转动并提示先对齐；回放也遵守同样规则。
- 保存及回放同时保留颜色和每块的空间方向，支持自由圆盘角度，手动改色会清除不再对应的打乱记录。
- 公开视频的页面及预览帧可读取，未获取完整字幕；规则依据用户明确说明，不能表述为已经完整观看并逐动作验证教程。
