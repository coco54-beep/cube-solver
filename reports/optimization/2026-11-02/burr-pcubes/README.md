# Burr 按 pCubes 布局替换

按用户指定，以 `bin/pCubes/Puzzles/Cubic/Bandaged/Bandaged-4/Burr.xml` 为布局依据，替换现有 `burr_cube`，没有新增重复型号。

- 28个双格长方块，覆盖四阶外壳56个小格；连块关系逐项对照XML中的两组`ParseTxt`坐标。
- 源坐标经正旋转`(x,y,z)→(-x,z,y)`映射到App，保持白上、红右、绿前的配色约定。
- 所有转动仍为整块约束下的90°倍数，禁止穿过连块。录入尺寸选择、两面联动、外壳切缝和打乱均使用同一新布局。
- 旧Burr布局记录增加版本检查，不会将旧连块身份静默套到新模型。

## 求解表

独立查询确认，新布局位于已有完整布局图中。通过16步合法路径重新选取求解基准，并对原配色群执行严格的坐标共轭，保持完整覆盖能力；没有只修改表头指纹。

1. 重新检查全部182070个布局的父子转移及新根可达性。
2. 重新检查全部1294884条合法转移的闭合与数量。
3. 对178条导出横截公式逐条执行实际Burr引擎，核对全部96面片置换，并确认连块布局回到新基准。
4. 更新`burr_shapes.bin`和`burr_group.bin`的基准、公式、指纹及布局版本。

证书：`solver-certificate.json`。构建工具：`tools/rebase_burr_pcubes.py`。旧资源只保留在开发快照目录，App不依赖pCubes或这些快照。

## 验证

- 203项相关测试通过，包含新布局对照、整块阻挡、40/100步无历史手动录入、全局朝向、取消、保存恢复和其他绑块回归。
- `manual/`：两个种子各30/100步，经可见颜色与连块边界重新录入，4例均求解并完整回放；解法142～568步，本机求解0.453～0.610秒。
- `ui-results.json`：800×600和390×844，以实际选块、旋转、选色、点格、确认和切面按钮重新录入六个面。
- `demo-results.json`：4个现有教学案例按新机构重新生成并完整回放。
- Burr目录缩略图已重新生成，Windows/Android资源选择检查通过。

本轮未打包，未进行Android真机测量。旧布局不再作为当前Burr型号提供。
