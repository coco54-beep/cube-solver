# VeryPuzzle #59 五魔球 D5：二十色三角配色修正

用户补图确认是十二根轴、每次 72° 的 VeryPuzzle 五魔球。此前错误地套用了普通五魔的十二色五边形配色；原 132 面片模型及其验收数据不能代表图中的配色。本次保留原十二根转轴、切深及圆切缝，修正为厂家实物照片展示的二十色三角区域。

参考：[厂家型号页](https://www.verypuzzle.com/product/59-megaminx-ball-d5/)、[厂家实物照片](https://www.verypuzzle.com/wp-content/uploads/2026/04/59-1.png)。用户原图和厂家照片保存在 `artifacts/expansion-references/confirmed-2026-10-27/`。照片只用于核对机构和外观，课程及算法由本项目编写。

## 当前模型

- 仍为十二根五重转轴、62 个物理块、切深为球半径的 0.75。切深是照片比例近似，非厂家实测。
- 二十个单色弧边三角角块、三十个双色棱、十二个各含五种颜色的转帽中央，共 140 片，每色 7 片。三角色区与五重转轴分开建模。
- 每个角块显示一个完整三角面；中央配色划成五片，能录入和显示中央的实际方向。沿用统一二十色选色、连续上色、逐面动画、撤销、拧动与回放控件。
- 按真实转层分别生成 140 面片动作，不再复用普通五魔 132 面片的置换；球面圆切平面与块分组保持不变。几何检测覆盖整球，转动后圆弧吻合。

## 状态求解

- 从输入颜色独立恢复双色棱与单色角的位置，并建立普通五魔机构的可见状态提升。单色角自身的三重方向不可见，不要求用户填写隐藏朝向。
- 先求解外围，再修正十二个转帽中央的五色方向。每个中央工具均用实际 140 面片动作验证，不会只因外围完成就错误显示已还原。
- 中央工具由相邻轴的 `(A B³)¹⁸` 独立构造；固定全部棱贴片和单色三角角位，十二个独立的方向向量在模 5 下满秩。无需新增大型求解表；解法尚不是最短解。
- 校验完整性、每色数量、局部组成、镜像、角与棱的排列奇偶及翻棱约束。中央可合法旋转；不会沿用旧三色角扭转校验误拒绝单色角。
- 旧十二色 132 面片记录无法无损转换，按面片数量安全拒绝恢复，避免错配下标或崩溃。当前 140 面片记录可正常保存恢复。

## 验证

- `reports/megaminx-ball-twenty-colours.xml`：29 项通过，含 24 例 30／100 步随机状态逐片重录、生产求解和完整回放，输入保持不变。
- 另测 100 例百步状态校验、12 个转帽分别独立旋转、非法单棱翻转、镜像中央、奇排列、不完整输入、取消和 JSON 保存恢复。
- 最终 `reports/megaminx-ball-twenty-colours-final.xml`：32 项通过（含上述 29 项，另加 3 项课程回归，不相加）；三角色区相邻关系筛选优化后重新验证。
- 原生界面验证脚本 `tools/audit_megaminx_ball.py` 核对 800×600 与 390×844 的二十色控件、实际点选、连续上色及撤销、逐面切换、拧动撤销、求解和完整回放。最新结果见 `visible/results.json`。
- 目录缩略图、原创课程中的块数和还原目标一并修正。早先 `megaminx-ball-regression.xml` 是旧十二色模型的历史结果，不作为本次二十色验收。

本轮为 Windows 验证；未做安卓真机和实物拧动验收，没有打包。
