# Drawing3：双子星外壳图纸核对

用户在讨论双子星 CAD 建模后提供 `C:/Users/ASUS/Desktop/Drawing3.dwg`，随后明确要求按新图替换原双子星。应用中的 `mf8_twins` 已改用新图的32片/面、192片总布局；录入、常规拧动、随机打乱、独立状态求解、回放、缩略图和原创教程同步更新。**这是限定常规转动的CSG几何模式，实物混转/变形轨道和内部连接尚未验收，不沿用旧平面模型的混转。**

## 来源和假设

- 原文件保持只读；工作区副本及 DXF 位于 `artifacts/expansion-references/twins-dwg/`。
- 原 DWG SHA-256：`b586334c54c1e8d5190dc74df428245a7856968a8af380cdad004c7755f2081c`。
- 图纸实际包含一个 10×10 闭合方框、十二段圆弧、六条内部直线；实体数据见 [entities.json](entities.json)。
- 用户已确认横竖十字线和四条菱形边全部都是实物切缝，预览按此处理。
- 六面预览暂重复同一面的切线，并利用图案的四重对称放置。单面图纸没有定义相邻面哪些区域属于同一刚性块、内部材料形状或转动联动。

## 已核对内容

中心圆弧是四段独立弧，图纸半径约 2.79999944，四条轴线方向保留缺口；没有补成完整圆。用户说明编号11、12、21、22这四块的半径尚不确定，因此该数值只作暂定图纸参数，不作为实物精确尺寸。外侧八段圆弧、十字直线和菱形边均按源图处理。

已增加四段圆弧联动的半径参数。更改半径后，用圆圆解析交点重新计算与相邻源弧的连接位置，保留轴向缺口，不单独缩放四个面片。原 DWG、提取实体和默认预览仍保留原图数值；参数方案另行输出。例如：

```powershell
python tools/preview_twins_cad.py --central-radius 2.8 --output-dir reports/expansion/2026-10-29/twins-dwg/radius-2p8
```

[半径对比图](radius-comparison.png)展示2.6、2.8、3.0三个示例，均以面边长10为基准，仅供比例核对，并非实物尺寸的测量或允许范围。当前照片有透视、圆角和缝宽，不能据此认定精确半径。

解析线线、线圆、圆圆交点后再离散曲线，端点进行归一化 `2e-7` 内的数值焊接。该处理用于消除 DWG 往返转换的微小接点误差，不修改原图纸，也不扩大实际切缝。

在用户确认的切缝下，每面形成 **32 个闭合分区**，全脸面积完整覆盖归一化正方形的面积4。全部内部线段参与分区，无遗留悬线或无效环。1°与0.5°两种曲线离散密度均得到相同分区数。

旧 `TwinsState` 每面有33个颜色字段，共198片；当前 CAD 外壳每面32区，六面共192个表面分区。二者不能按下标直接替换，也不能仅贴一层新线条就宣称旧机构已修好。

## 应用替换与限制

新几何延拓使用十二个棱轴球面、四个过心对角切面，并根据棱球重叠数量选择性保留三个坐标切面或中央球面。这是与单面CAD吻合、在立方体正旋转下封闭的候选内部构造，不是从单面图纸证明出的厂家内轨。中央四段圆弧仍暂用2.8/面宽10。

通过解析全体体积区域得到288个正体积原子区，归并为190个逻辑材料组。其中152组有可见色片（120单色、24双色、8三色），38组为隐藏材料。隐藏材料参与全部常规转层的选择和占位验证，不用表面中心点代替整块判断。全24种立方正旋转保持该材料分区；棱轴球面绕轴180°、对角切面绕轴120°的操作闭合。当前不开放60°角转或旧J混转角；范围外输入保留并提示尚未覆盖。

每片输入仍保持独立，共192片。求解时额外证明了48对颜色在本常规动作群下的等变关系，将搜索表示降到144字段；不满足关系的输入提示当前模式未覆盖，不据此认定实物无解。两组24字段使用自主发现的10步循环，余96字段使用完整群证书。生产求解表为 `solver/data/twins_cad_colour_group.bin`（36652字节）；旧布局表退出生产目录，参考副本保存在工作资料目录。

`cube/twins_state.py` 是新应用状态；旧平面基类移到 `cube/planar_twins_state.py`，仅供太阳二号、双鱼座等原有模型复用及回归。它们没有被替换成双子星CAD。新观察数据和会话存档包含几何指纹；旧布局或不同半径的记录被拒绝错套，原文件不改动。

实际页面检查覆盖800×600和390×844：连续选色点面、草稿确认/取消、隐藏材料补全、清除取消/确认与撤销、角转120°、拒绝未验证60°、求解回放到尾及回到起点、再次打乱与撤销、取消保留输入。两种尺寸均通过，同一状态回放1173步；这不是最短解保证，也不是安卓真机性能验收。
