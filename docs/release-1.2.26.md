# 1.2.26 — 使用说明在手机上可读 / Readable Help on phones / スマホで読める使い方

## 中文

- 修复手机上的**使用说明**弹窗：面板尺寸原来被限制在约 760×560 原始像素，在高分辨率手机上只占很小一块；现在随屏幕缩放（约 92% 宽 × 70% 高）。
- 文字改用密度感知字号（正文 18sp、小节 21sp、标题 26sp），在手机上可正常阅读。
- 桌面端不受影响（缩放系数≈1，与之前一致）。

其他内容与 1.2.25 相同：拍照识别按录入页顺序逐面扫描并提示转动方向、各输入页「赋予初始值」一键还原并预置中心块、首页底部操作栏、打乱步数随规模放大、求解失败提示多语言。

## English

- Fixes the **Help** dialog on phones: the panel was capped at ~760×560 raw pixels and occupied only a small box on high-resolution devices. It now scales with the screen (~92% wide × 70% tall).
- Text uses density-aware sizes (body 18sp, section 21sp, title 26sp), readable on phones.
- Desktop is unchanged (scale ≈ 1).

Everything else is the same as 1.2.25: face-order photo scanning with turn hints, one-tap **Set initial** with pre-placed centres on the input pages, the Home bottom action bar, size-scaled scrambles, and localised solve-failure messages.

## 日本語

- スマートフォンの**使い方**ダイアログを修正：パネルは約760×560の生ピクセル上限で、高解像度端末では小さく表示されていました。画面に応じて拡大します（約92%幅 × 70%高）。
- 文字は密度対応のサイズ（本文18sp、小見出し21sp、タイトル26sp）に変更し、スマホでも読みやすくしました。
- デスクトップは変更なし（スケール≈1）。

その他は1.2.25と同じです：入力画面の面順に従う写真読み取りと回転案内、ワンタップの**初期値を設定**（中心ピースの自動配置）、ホーム下部の操作バー、規模に応じたスクランブル、求解失敗メッセージの多言語化。
