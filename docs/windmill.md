# 三阶风火轮魔方

入口：异形魔方 → 特殊异形 → 风火轮魔方。

- 三阶机制，26 个独立块；外壳绕竖直转轴偏转 30°。
- 统一的内部切面经过复原外壳的竖直棱，形成角块三角面、上下层棱块梯形面、侧面矩形中心与棱块。
- 使用形状与颜色卡片录入，支持六色自定义、恢复默认颜色、随机打乱、清空和撤销。
- 点击块保持当前镜头，左右箭头切换视角；独立拧动页使用内部转轴进行触摸选层。
- 从录入状态生成三阶解法，随后修正四个侧面中心的方向，并在返回成功前检查复原外形。
- 上下纯色正方形中心的旋转不可见；中心修正允许这些中心吸收虚拟朝向，不将其作为输入错误。
- 接入现有求解进度页和横竖屏播放页，播放箭头对应上一步与下一步。
