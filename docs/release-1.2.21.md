# 1.2.21

包含主分支中已提交、尚未发布为 GitHub Release 的更新，以及以下内容：

## 异形魔方目录扩充
- 目录新增：恐龙／格子、转面八面体（FTO）、足球（Tuttminx）、二十面体、繁花五魔方、枫叶、四叶草、八叶花、空心三阶、空心魔塔、SQ1、镜面三阶魔塔，以及形状魔方（变形金刚／潘多拉／风火轮／移棱）。
- 异形目录与特殊异形页的卡片改为**3D 示意图 + 名称**（不再用缩写字），并统一缩放比例；圆壳类（战鼓／五面体／魔塔／繁花等）不再被裁切。

## 求解
- 恢复 **N 阶范围 6–17**（此前被误削减为 6–14）；实测 15 阶约 23s、17 阶约 37s。
- 五面体：2/3 阶改用**全表最优**（7–12 步）；4/5 阶改用**核心注入 + 改进搜索**，步数由 1000–2800 降到约 500–800。
- 战鼓：接入通用改进搜索，步数小幅下降。
- 镜面三阶魔塔：改用两阶段最优求解，步数由 258–615 降到约 6–22。
- 高阶五魔方提速（8 阶约 41s→12s、13 阶约 220s→74s）：numpy 搬运 BFS、预计算扭转 gadget、块级交换子预筛、native beam 增量计分。

## 界面与语言
- 修复**浅色／深色切换**后卡片不刷新（卡片未绑定主题事件）。
- 设置页移除「镜头跟随」控件。
- 修正帮助文案结构（英文／日文的图标说明误置于中文），并补齐三语帮助与异形名称的日语翻译；异形录入／拧动页解说与弹窗全部日语化。

## 打包
- `requirements` 增加 **numpy**，随 APK 一并打包（此前缺失会导致 megaminx／football／war_drum 等求解报错）。
- 固定 `.sh` 为 LF 行尾，避免 buildozer 脚本在 WSL 下因 CRLF 失效。

README（英文／中文／日文，新增日语版）与文档已同步更新。本次主要为功能与界面调整，求解结果均按重放校验；随机状态的全面覆盖与真机性能评测仍不完整。
