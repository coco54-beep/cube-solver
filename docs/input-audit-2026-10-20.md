# 魔方录入检查（2026-10-20）

## 检查结论

检查了目录中的 158 个阶数、型号入口，都能打开对应录入页。
针对录入、模型重建和相关操作的 270 项检查通过。
这些是桌面软件检查，没有使用手机、实物或相机照片，也没有打包 APK。
入口打开通过不等于该型号所有可能状态都已验证。

## 本次修复

1. **六种绑块魔方**：原来只能在预设连块位置录入。现在允许按实物打乱后的
   位置放置各尺寸色块，再根据该型号固定的刚性组，匹配真实块位与方向。
   相邻两面必须属于同一块、不能覆盖已填色格子、尺寸数量必须正确。
   进入拧动、求解前提交重建结果，不再只在旧模型上涂色。
2. **圆圈二阶**：手动配色后的固定角位置，在进入拧动前重新识别；
   与求解使用同一位置，避免圈内块沿旧规则转动。
3. **普通镜面系列**：补上棱块、中心块的重复检查。高阶中实际同形的块
   自动分配内部身份，保留原有几何，不要求用户区分隐藏编号。
4. **草稿与保存**：绑块型号、普通魔方分别保存草稿；同时保存连块。
   恢复会话时纳入彭罗斯和绑块录入数据；清空、撤销和重做保留连块与颜色的一致性。
5. **提示**：恢复录入布局时，取消“可复用上次解法”的不准确承诺。

| 可变形长方体、迷彩三阶 | 由六视图重建颜色、外形、深度和块边界；比较时不依赖隐藏块编号 |

颜色和形状测试由软件模型生成目标，再从输入表示重新构建。
它们可以发现输入表达不足、转层信息丢失和页面间状态错配，
不能独立证明软件模型与每个厂家实物的切割完全一致。

## 仍然存在的范围限制

- **圆圈系列复杂手动状态**：录入表示可用，完整自动求解仍未实现。
  无有效操作记录时采用有预算的短搜索，最多六步范围；颜色数量正确不代表完整可解。
- **手动绑块求解**：本次匹配保证型号刚性组、颜色和几何一致，
  不证明状态在绑块限制下可达。现有求解器会逐步检查合法性，
  普通三阶、四阶解法无法合法回放时仍可能失败。
- **六视图**：此次样例带深度信息。实物观察存在遮挡或多个内部解释时，
  仍需补充视图或深度；应提示不唯一或超时，不应直接生成猜测的状态。
- **转棱系列**：检查仅覆盖当前实现的 180° 常规状态，不含 jumbling 变形。
- 本次没有做所有型号、所有打乱状态的穷举或全套自动求解检查。
