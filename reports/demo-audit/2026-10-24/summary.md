# 新增型号原创教学接入记录

## 本轮内容

按用户“没有现成的就原创，不用别人的教程、不直接放链接”的要求，新增教学全部在应用内阅读和播放，移除了外部资料区与浏览器跳转代码。

- **32 款，128 章**：每款四章，包含识别、实际操作、完成条件及常见错误。
- **156 个三维案例**：基础转层、局部操作、核心调位／方向修正、侧中心方向及独立循环。
- **51 个三块循环工具，覆盖 27 款**：其余五款有针对各自真实核心／中心方向的公式案例。
- 教材在应用内按章分页，每章可打开相应演示，第四章可生成本型号的完整还原实例。
- 完整实例在没有现成有效阶段时，从实际状态生成归位检查点；阶段起点取自同一条完整回放，不凭文字虚构“中心已齐”等目标。
- 独立教材导出为 `docs/expanded-original-tutorials.md`，与应用中的章节文字和案例公式一致。

## 原创与公式的含义

讲解和学习结构由本项目编写，不转载外部文章或视频。局部循环工具由本项目的实际合法转层和既有机构数据推导、筛选，再检查完整作用范围；“原创”不表示宣称某个数学动作序列此前从未被其他人发现。

核验不止是“公式逆序后能还原”：

1. 贴片机构检查完整置换，确认只有图示三个物理块移动、不会拆开块，且没有残留朝向。
2. 字母形检查全部刚体朝向，确认核心及其余外伸块不变；分别提供外伸角组和棱组工具。
3. 镜面机构还检查未参与块的完整刚体朝向，防止颜色不变但高低／中心方向被改变。
4. 三块循环连做三次恢复原始完整状态。
5. 核心工具另查三角块循环与两角朝向修正的真实作用；不把已不可见的方向当成需调整的教学情况。

归位检查点只统计已达到本次最终目标、并在余下动作中保持的块；检查段与完整解法再次从原始状态回放。已有有效降阶阶段则沿用真实中心、配棱等阶段。

## 模型与界面

- Trajber 使用四阶核心与八面体外壳，启用对应演示；没有退回三阶模型。
- 十二面体二／三阶、Container、Blanker、镜面 Kilominx／Megaminx 均使用各自真实三维模型。
- I／L／T／X／Tri／Temple／Cross 的六视图录入书本入口进入对应型号教学。
- 教学模型与用户录入分开，返回时保留输入。
- 原创三块工具对固定工作位置标号；字母形与镜面五魔的刚体视图补上同样的编号，编号不随循环中的块移动。
- 章节换页及关闭后，旧章节按钮回调作废，防止打开错误案例。
- 表达式按真实最小角显示，反向 72°不会写成要求硬转的正向 288°。

## 检查记录

- `original-inventory.json`：32 款的章节、案例和循环工具数量。
- `expanded-teaching.json`：每款一个独立种子 54、24 步合法打乱；移除打乱历史后调用正式求解器，再从原始状态回放检查。
- `ui/controller-results.json`：实际录入书本入口、教程分页、三维模型类型、下一步／上一步、半途停止、返回页和输入保留。
- `regressions.xml` 与 `final.xml`：教程、真实模型作用及公共演示／页面回归。

最终统计以这些文件最后一次执行结果为准。

本轮最终合并回归 **393 项通过、0 失败、0 跳过**；32 款的完整状态求解回放与实际教学控制均通过。汇总保存在 `results.json`。这是指定案例与动作检查，未将其表述为所有状态或所有人工学习情形的穷尽验收。

## 数据和适用范围

新增公式教学数据 `demo/data/expanded_macros.json` 约 **12 KB**，只保存短教学词及效果记录，没有复制整套求解表。Windows 与 Android 的既有资产规则均包含此 JSON。

本轮为 Windows Kivy／ANGLE 检查，桌面 800×600、竖屏 400×850；未进行 Android 真机触摸验收或重新打包。

一个完整打乱实例通过不代表所有手工输入均秒解，也不代表已经穷尽每个型号的特殊情况。局部工具只适用于可达的对应块组及方向；完整演示使用其显示的起始状态，其他实物状态应从录入生成对应还原过程。

## 复现

在项目根目录依次运行：

```text
python tools/build_expanded_teaching_macros.py
python tools/export_expanded_teaching.py
python tools/audit_expanded_teaching.py --solve --timeout 60
python tools/audit_expanded_demo_ui.py
```

构建工具只读取既有机构数据，输出小型教学公式文件；不重新构建大型求解表。
