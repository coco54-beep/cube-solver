# 1.2.37

- 修复所有系列选择阶数后界面卡死：公共按钮沿父级查找所属页面时，遇到 parent 指向自身的窗口进入死循环。现在弹窗按钮能正确结束查找，离开页面后的旧按钮仍保持拦截。
- Mixup 输入模型复用静态表面，观察旋转不再重复构建相同几何；修改组成、方向、颜色和撤销后及时失效重建。
- Mixup 切换画笔只更新画笔状态，保留组合卡片和模型，继续支持同色连续上色。
- 旧存档先检查页面结构，再恢复魔方，避免无效页面导致状态只恢复一半。
- 修正 Android 页面自检触发，清除旧报告后运行，报告失败时返回失败结果。

验证和 Android 模拟器实际点选结果见 reports/optimization/2026-10-24；本版本未增加魔方型号。
