# 同类魔方录入界面统一（2026-10-24）

## 公共规则

- 录入页顶部使用相同的返回、标题、帮助位置和尺寸。
- 横屏为模型与操作区左右排列，竖屏为上下排列；操作区可滚动。
- 常用动作按「拧动、随机打乱、清空、撤销、设为还原态、求解」排列。
  SQ 在录入页直接拧动，公共动作行省去独立拧动入口。
- 已还原态统一使用靶心图标。相机复位使用回转图标，放在观察操作区。
- 支持修改配色的页面统一进入 `PiecePaletteScreen`，可整体编辑、恢复默认、
  保存或取消。多面体只显示型号实际需要的颜色数量。
- 选块卡片采用四列、每页最多八项，分页位于卡片下方；只有一页时隐藏分页。
- 方向、组合、深度、圆盘角度等型号操作继续放在相应操作区。

公共组件在 `ui/widgets/entry_controls.py`，避免各个子型号自行定义按钮顺序和分页。

## 各录入方式

| 方式 | 代表型号 | 本次统一内容 |
|---|---|---|
| 逐面填色 | 普通阶数、彭罗斯、普通 Tangram、五魔、八面体、不能变形的长方体 | 公共页头；原有逐面填色操作继续使用。多面体配色由弹窗改为独立配色页 |
| 选块与方向 | 粽子、移棱等变形、镜面、Blanker、魔鬼、镜面五魔、Container | 共用横竖屏布局、四列卡片、八项分页、观察与方向控件位置、动作行 |
| 形状卡片与颜色 | Tangram Extreme | 继续使用真实 3D 模型与逐面观察，共用卡片分页和动作行 |
| 组成与上色 | Mixup、Mixup Plus | 配色按钮移到操作区，右上角统一为帮助；还原态和相机复位图标分开；共用动作行 |
| 六视图 | 迷彩、可变形长方体、字母扩展 | 共用页头和动作行；保留轮廓、深度、匹配及取消，移除重复的清空和撤销按钮 |
| 层图与块卡片 | SQ-1、SQ-0、SQ-2、Super SQ-1 | 同一页头和动作顺序；块卡片使用公共分页，相机复位归入观察操作区 |

Blanker 继续使用当前八个实体块的形状与方向录入，没有改成六视图。
配色保存还会刷新彩色块卡片，使卡片颜色与主模型保持一致。
魔鬼类的对齐／开合按钮移到方向操作附近，避免落在镜头设置之后。

## 未录入灰模与线条

所有主要录入渲染器改为引用 `renderer/entry_style.py`：

| 用途 | 统一规则 |
|---|---|
| 尚未录入的面或实体块 | 不透明中性蓝灰，基色 RGBA `(0.43, 0.48, 0.53, 1)` |
| 三维灰模光照 | 同一光源和亮度范围，保留面朝向的轻微明暗差异 |
| 内部塑料与切开后的背面 | 深灰，区别于尚未录入的外表面 |
| 块缝与棱线 | 深灰，常规线条半宽 `0.75dp` |
| 二维外框 | 半宽 `1dp` |
| 采样网格与空位辅助线 | 较浅、半透明，半宽 `0.4dp` |
| 当前选择轮廓 | 青色，半宽 `1.6dp` |

这里的半宽与 Kivy Line、三维网格描边的计算方式一致。
三维实际显示颜色会随朝向略有变化，不要求每个像素完全相同。
已确定的参考中心仍显示其颜色或银色材质。

普通魔方、彭罗斯等变形、移棱/粽子、镜面、Blanker、多面体、长方体、
Mixup/Plus、Tangram/Extreme、SQ 层图和六视图均接入公共样式。
镜面、Tangram Extreme、Mixup、长方体与 SQ 等使用完整实体面作为贴面，
未录入灰模和已填色面共用屏幕空间描边。
移除贴面按比例缩小产生的宽黑框；粽子类也移除随块尺寸变化的白色衬边。
因此填色前后、不同大小的块和不同缩放比例下，块缝的颜色和目标线宽一致。
该显示处理不修改实体碰撞几何、录入状态或求解状态。

六视图先画格子填色，再统一画四周边界，避免相邻格子覆盖半条块缝，
也避免漏画已录入面片的左边和上边。采样网格仍与实际面片边界区分。

灰模检查记录另存于 `reports/input-audit/2026-10-24/entry-gray-style/`：

- `review.json`：28 个代表配置的横竖屏页面，共 56 个实例。
- `partial/review.json`：9 个代表配置的部分录入与撤销，共 18 个实例。
  包含普通魔方、镜面、变形、八面体、迷彩、Mixup、Mixup Plus 和两种 Tangram。
  检查填色或选块后仍有未录入灰模、绘制不改变数据、撤销恢复原状态。

检查使用实际桌面页面，没有运行整套求解测试或生成安装包，尚未做 Android 真机验收。

### 已填色模型的块缝补齐

已填色面与灰模现在都使用同一深灰色、`0.75dp` 半宽的屏幕描边。
Mixup、Tangram、长方体、镜面和 SQ 的彩色贴面不再按比例缩小来露出塑料边框；
粽子二阶/三阶的白色衬边改为真实面边界的描线，不画曲面细分三角形的内部边。
SQ 闭合时的显示层面相接，层间线同样由公共描边产生。
这些改动仅涉及显示面与线条，没有修改魔方状态和转动规则。

完整填色的桌面预览保存在 `reports/input-audit/2026-10-24/colored-seams-preview/`，
包括粽子三阶、镜面三阶、镜面塔、固定长方体、Mixup Plus、Tangram Extreme、
SQ-1、SQ-2 和 Super SQ-1，共 9 个代表配置。此次补充没有运行算法测试。


## 局部录入反馈（2026-10-25）

普通魔方编辑时维护颜色计数，只有颜色改变的物理块重新检查重复色与相对色；恢复、擦除和撤销均重新同步缓存。缺失或整体奇偶约束仍在最终校验处理，局部提示不证明完整状态合法。

Mixup 的缺失区域、两侧组成冲突和新形状与邻块相交会携带可定位的位置。修改被拒绝时保留原组合、颜色和邻块，定位只改变选择，不改变输入。
