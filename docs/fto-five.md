# 五阶转面八面体（FTO）

转面八面体入口现在提供2、3、4、5阶。五阶每面25个三角色面，合计8面、200个色面、146个实体块；绕面转120°，外层和内层可分别选择。

五阶采用相对于八面体内切半径的切割深度1/5、3/5，连同对面切割形成五等分三角网格。它是规则平直外壳的几何模型，不包含实体塑料圆角。已有二至四阶的切割参数保持原值。

## 接入范围

- 阶数选择及中文、英文、日文阶数名称。
- 模型、逐面录入、触控拧动、随机打乱、还原回放和会话保存。
- 拍照识别支持范围扩到五阶，复用八面体三角形取色模板；尚未在手机确认识别效果。
- 五阶以内的公式教程自动读取对应几何的独立轨道三循环，提供情况识别、标记块及正反向公式。

## 求解准备

`python tools/build_fto.py 5` 生成并合并五阶资料到 `solver/data/fto_core.bin` 和 `solver/data/fto_cycles.bin`，保留原有二至四阶记录。

核心表覆盖六个四色角和两个四块中心轨道，共32个标签。额外11个十二块轨道使用预制搬运公式。独立轨道公式中最长的160步，在分阶段计划中改用10步；其他阶段公式为4或8步。分阶段公式允许尚未处理的轨道变化，严格保留已完成轨道。

生成器核对每条核心公式与置换一致，并核对每条分阶段公式的三循环及保护范围。这里的4–10步指搬运原语，整颗魔方的总解法长度取决于录入状态，不代表全局最短解。

同时修正FTO核心分派：优先读取完整预制表。通用小核心搜索不包含四色角，不能单独用于判定FTO核心完成。
