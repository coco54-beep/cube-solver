# 六款绑块统一为六视图录入

2026-11-03。覆盖 Fused Cube、Two-Bar、Bandaged C、BiCube、AI Cube、Burr Cube。目录分类和各型号固定绑块定义不变。尚未重新打包 APK。

## 操作

- 共用迷彩三阶的六视图布局、选色画笔、网格、拖框、撤销、匹配任务和失败提示。
- 先选颜色，再连续点击填色。拖框表示同一张物理绑块面片；相邻同色但有切缝的面片分别圈出。
- 点击已录入面片可整片换色，保持其切缝。无需尺寸卡片、旋转卡片或先完成一个尺寸再录下一个尺寸。
- 固定立方体没有空位、外露无色面或观察深度选项，隐藏相应按钮。
- 六面的颜色与面片边界，交给原有固定库存重建器联合匹配。颜色不会自动把相邻块粘成一块，也不根据打乱历史猜状态。
- 打乱结果可继续修改；匹配、取消、重试、拧动写回、返回录入和撤销保持一致。求解仍使用原有各型号求解器，失败返回此输入页。
- 分型号保留草稿。旧选块录入缓存迁移到新页，保留颜色、切缝和未录内容；拧动中的缓存保留真实绑块模型。

## 验证

`combined-tests.xml`：264 项通过。包括 18 组独立重录（六款 × 30/100 步及三个种子配置），丢弃打乱历史后，通过同一框选接口填写颜色和面片。重建状态的色面、物理面片和合法转层限制与源状态一致；原状态保持不变。

其余检查包括连续涂色、同色相邻块保留切缝、整片换色、撤销、不完整输入、预算耗尽、取消、求解交接、旧缓存迁移、当前草稿恢复、拧动缓存与页面返回，以及现有迷彩、拍照、启动恢复和通用按钮回归。

`native/native-results.json`：12 个实际 Kivy 页面案例通过（六款 × 800×600 / 390×844）。通过页面的选色、框选处理函数重新录入 100 步打乱状态，后台匹配后检查合法拧动、回到录入页及撤销。不是直接把打乱对象注入录入页。

`restores/native-results.json`：真实延迟启动流程的 3 类恢复通过：旧选块页、未完成六视图、拧动页。测试采用独立临时存档，未修改用户进度。

## 边界

本次改进录入与状态交接，没有增加求解器搜索范围。结构匹配通过不等于任意手工状态均可还原；深层搜索的原有限制仍保留。尚未在安卓真机上检查新的六视图操作。
