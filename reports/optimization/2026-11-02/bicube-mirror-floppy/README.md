# BiCube、镜面迷彩、普通 Floppy

本轮替换 BiCube，新增两款独立型号。沿用现有分类，没有新增类别；有色迷彩与 Super Floppy 保留。

| 型号 | 入口 | 实现 |
| --- | --- | --- |
| BiCube | 绑块系列 | 使用本地 pCubes Bicube.xml 的连块坐标，重建布局图与配色群，旧布局存档版本隔离 |
| 镜面迷彩三阶 | 镜面系列 | 独立偏移银色外壳、26实体、54银色面片、三块选择性细分中心；支持六视图、拧动、打乱、手动状态求解与教学 |
| 1×3×3 Floppy | 长方体系列 | 普通四边180°翻转机构，保持外形；逐面颜色输入，与允许90°变形的 Super Floppy 分开 |

## 机构与求解

BiCube 的九个双格连块与一块包含7个可见格的2×2×2实体，直接对照 `bin/pCubes/Puzzles/Cubic/Bandaged/Bandaged-3/Bicube.xml`。完整布局图121节点、504条转移全部重建，回形配色群阶60。源坐标采用正旋转 `(-x,z,y)`。BiCube 记录版本为3，旧版记录不被静默套用。

镜面迷彩参考 `bin/pCubes/Puzzles/Cubic/Camouflage/Mirror Camouflage 3x3x3.xml`，并非把旧迷彩改为银色。D=.2归一化为1，偏移外壳经 `(x,z,-y)` 映射。四个不可见内格不参与碰撞；每次转动检查完整实体不跨越切面。

银色六视图首先自动匹配；缺少颜色线索而出现歧义时，补充标出的可见面片高度再匹配。12个30/100步实物观测模拟中，补充0～4处高度后均匹配成功；没有把源帧、隐藏块身份或打乱记录传给匹配器。

求解加速独立编译68040个半体组合投影、2295个受阻挡约束的回形宏公式及15张投影距离表，之后以实际模型逐步回放。加速搜索不删除完整回退搜索的分支。三层短状态表压缩为约115KiB，避免额外携带约1.6MiB的五层表。全部5项镜面迷彩求解资源合计1,275,096字节。重建：`tools/build_mirror_camouflage.py`。软件运行不依赖 pCubes。

普通 Floppy 使用完整192状态最短搜索，不增加离线求解表。独立遍历全部状态并逐个求解，最短解最长8次半转；不允许90°转动或穿过中央薄层。

## 验证

- 145项相关测试通过，覆盖新模型、手动颜色/结构输入、30/100步深状态、实体碰撞、反转、取消、存档，以及原有迷彩、Burr、Super Floppy 回归。
- 13项入口、拍照、教学和 BiCube 实际录入控件测试通过。
- 缩减短状态表后，新三型号41项测试再次全部通过。
- 实际 App 在800×600与390×844尺寸下，从现有目录进入三型号；普通 Floppy连续填色、撤销、切面动画，镜面迷彩区域填入、撤销、切面、进入3D拧动均通过。见 `ui-results.json` 与同目录PNG。
- 三款目录缩略图已生成；Windows/Android资源选择审计通过。

这些结果是软件模型与本地定义的核验，本轮没有打包，也没有安卓真机测试。复杂镜面手动状态仍可能需要更长搜索，可取消并保留输入。
