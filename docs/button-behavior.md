# 录入、拧动、还原页按键规则

## 录入

| 按键 | 行为 |
| --- | --- |
| 随机打乱 | 先生成合法布局，再替换录入；不增加确认弹窗，可撤销。 |
| 初始值 | 将当前型号设为已还原并已录入；可撤销，不改变镜头锁定、跟随设置。 |
| 清空 | 先确认再清空；可撤销，不更换型号、阶数或配色。 |
| 撤销、重做 | 恢复录入数据并清除过期校验；支持重做的页面，新编辑会清空旧重做分支。 |
| 校验 | 检查当前录入并标出问题，不自动打乱或求解。 |
| 求解 | 使用当前录入；求解期间不允许同时改录入或再次启动求解。 |
| 换面 | 当前翻面结束后才能再次换面；翻面期间不并发执行随机、清空、初始值等操作。 |
| 返回、切页 | 保留当前输入；同一布局再次显示时不清空撤销记录。 |

普通魔方的随机、公式打乱、初始值和清空均按一次完整编辑保存，可一次撤销。
粽子、镜面和其他按块录入的魔方保留其结构与预置中心规则。

## 拧动

| 按键 | 行为 |
| --- | --- |
| 正转、反转、拖动拧层 | 动画或镜头跟随尚未结束时不并发启动新转动。 |
| 撤销、重做 | 回放逆动作或原动作；新拧动会清空旧重做分支。 |
| 单层、宽层 | 拧动期间不切换，避免操作模式与当前动作混淆。 |
| 返回 | 保存拧动后的状态回到录入；转动未完成时暂不返回。 |

普通魔方、颜色异形和粽子/镜面类返回录入时，保留原录入的撤销历史，并记录本次修改。

## 还原播放

| 按键 | 行为 |
| --- | --- |
| 播放、暂停 | 暂停取消后续自动走步；已经开始的一步正常结束。 |
| 上一步、下一步 | 先暂停自动播放，再手动走步，不在手动操作后自动续播。 |
| 回到开头、跳到结尾、返回录入 | 打开确认框时暂停；取消后保持暂停；确认后执行跳转或返回。 |
| 进度条 | 停止自动播放，按目标步数重建显示状态。 |
| 速度、停留 | 调整播放节奏，不改变录入、解法或当前步骤。 |
| 复位视角 | 只恢复观察角度，不等同于将魔方恢复到已还原状态。 |

## 镜头设置

锁定视角会将跟随设为 0；开启跟随会解除锁定。手动解锁不会自动开启跟随。
页面切换保留设置，复位视角不更改设置。

本轮依据代码梳理并完成语法检查，尚未执行新的界面或手机测试。

## 求解中

普通魔方、粽子、镜面、各类多面体异形和 SQ1 统一进入求解页，显示模型、当前处理阶段、进度条和文字“取消”按钮。

- 有进度回调时显示该阶段进度；没有进度时保持准备中，不编造总进度。
- 取消立即返回原录入页，保留输入和撤销历史；后台未及时退出的旧任务不得改变新页面。
- 成功进入对应的还原播放器；失败返回原录入页，并统一弹出“求解未完成”说明。
- 取消、离开页面后，旧任务的进度和结果一律忽略。
