# 三阶粽子魔方

主页的「三阶粽子魔方 · 自选四色」进入专用录入页。此模式使用三阶六轴结构和异形块模型。

## 配色与拿法

- 直接点顶部四个编号色块，用选色器选择对应的颜色。改色窗口只提供选色器和四面展开图，去掉六个标准色按钮。
- 四面展开图的 1、2、3、4 对应顶部色位，青色轮廓标出当前改色的面。展开图按照模型实际的四面邻接关系绘制，选色时同步预览对应面，方便对照实物确定配色顺序。
- 色位顺序决定四面配色；选择已用颜色会交换两个色位。改色会保存配色，并保留已录入的块、中心朝向和当前视角，重新打开应用仍使用所选颜色。
- 改色窗口中的“恢复预设”一键恢复默认的红、黄、蓝、绿四色及顺序，保留已录入的块、中心朝向和当前视角。
- 点问号查看完整彩色参考模型，按前轴 F 和上轴 U 的双色中心确定拿法。其余四轴的色对也必须匹配；如果不匹配，调整四色顺序。
- U/D 是上下转轴，F/B 是前后转轴，R/L 是左右转轴。它们对应六个双色中心，而非四个四面体颜色面。

## 录入变形状态

录入不需要先恢复四面体外形，也不需要知道打乱公式。

1. 六个双色中心会按所选配色和初始朝向预填，方便定位；新建或清空会恢复这些初始中心，改色则保留现有中心朝向。对照实物，选择中心的形状卡片或用中间的环形箭头调整朝向。中心计入录入进度，其他二十块仍需录入。
2. 录入八个角位置。按实物选择三色尖角或单色小三角，旋转尖角使颜色顺序匹配。
3. 录入十二个单色梯形位置。选择颜色，用弯箭头匹配梯形的倾斜方向。
4. 点击模型中的块，自动切换到该块对应的输入选项。青色轮廓标出当前块；灰色表示尚未确认，深色是变形后露出的内部切面。
5. 左右箭头沿用高级输入的平滑翻转动画和正视镜头，切换观察方向；中间的环形旋转箭头调整当前块的朝向。录入页不支持拖动改变视角，点选、录入和撤销也不会自动转动模型。切换视角不改变魔方状态或已录入数据。保持实物参考拿法不变，输入完整后点勾校验，点播放图标求解。

同色梯形的三个内部编号，以及单色小三角不可见的内部朝向，由程序自动匹配。用户不需要编造普通三阶的六色贴纸。

### 随机打乱

底部的交叉箭头与高级输入使用同一个随机打乱生成器：从当前配色的还原状态开始，执行随机转动，生成完整的变形魔方并录入全部 26 块。随后可直接点播放按钮求解；撤销按钮恢复生成前的录入。生成打乱保持当前观察视角。

## 求解和还原

先用三阶两阶段算法还原活动块，再用不改变角棱状态的中心公式校正六个双色中心。每次求解都会在异形模型上应用全部步骤，检查颜色和几何外形同时复原。

求解按完整还原步数比较方案：中心路径按实际动作数搜索，不再只比较中心公式组数；连续同轴动作可合并和抵消。已经合法的内部块标记保持不变，避免随机打乱被重新编号。程序还会尝试更短的三阶解及少量预转动候选，比较活动块与中心校正合计的步数，保留已找到的较短结果。

中心公式还会保留同一校正效果的多种写法，在有界搜索中调整公式顺序，并结合前一阶段的末尾动作寻找抵消。角棱候选交替尝试同色梯形的等价三循环编号和单色小三角的成对内部朝向；这些替换保持块的几何形状与颜色完全相同，并检查三阶排列和朝向约束。它们只用于后台搜索，不改动用户录入或可见模型。重复的三阶搜索状态在本次求解中复用结果。

候选解按完整动作数比较，只在更短、且应用到原始输入后颜色与外形都复原时替换当前结果。基础解始终保留；中心衔接搜索与等价块搜索共用额外预算，不为新搜索另加时间额度。

额外比较默认使用 2.5 秒搜索预算；底层三阶搜索的超时是软限制，寻找第一个解时可能超出预算。结果仍按完整几何外形与四色配色校验，不保证全局最少步数。已还原的魔方直接返回零步。

还原页面显示真实块结构和转动后的变形，支持逐步、自动播放、回到开头、跳到结尾及返回专用录入页。退出录入页会保留本次尚未完成的录入；配色持久化，录入草稿目前只保留在本次应用进程中。

粽子回放及教学案例采用对称的初始视角：还原状态的尖角朝上、底边水平，三个可见颜色面均衡展示。回放每次进入时恢复此视角，环形重置按钮也回到该角度。录入页仍按六轴正视方式观察。

显示模型采用整体连续的曲面四面体外形：四个面有弧度，棱和顶角平滑过渡。先生成完整曲面，再按三阶机构的平面切割成块，保留中间三角面的面积；很窄的白色塑料间隔只出现在真正的块边界与颜色分界，曲面细分线不显示。录入模型、形状卡片、还原回放和教学演示共用此外观；教学缩略图也会重新生成。曲面显示网格按块缓存，转动时跟随对应块一起运动。

计算仍依据三阶切割结构和准确的块形匹配；曲面是显示层的外观处理，内部切割面保持平面。示意模型的曲率与具体品牌实物可能略有不同。

## 教学演示

录入页顶部的书本图标进入演示目录，帮助窗口也提供“教学演示”入口。目录和演示页共用其他魔方的布局，按阶段列出异形缩略图、公式与说明。使用当前选择的四色配色，演示独立于录入草稿。

- 转轴与变形：右轴四分之一圈、上轴逆时针、前轴半圈。
- 角块与梯形块复位示例：右侧插入、前侧插入、角块朝向组合。
- 双色中心校正：中心半圈校正、成对中心校正，使用求解器采用的中心公式。

每个案例的初始状态由对应公式逆序生成，执行完整公式恢复该案例。它们用于学习动作，不是对任意打乱都能直接套用的完整解法。

底部从左到右为：回到开头、撤回一个动作、自动播放／停止、执行一个动作、重置视角。前进和后退均带转动动画，动作计数按公式记号统计，半圈算一个动作。自动播放从当前进度继续。顶部循环图标可切换演示魔方，返回目录会显示当前魔方的案例，目录返回粽子录入页时保留草稿。
