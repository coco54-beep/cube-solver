# 三瓣、五瓣魔豆立体外壳

依据用户提供的蓝色五瓣款实物照片，替换了原先的平圆底板与简单中心圆片。三瓣、五瓣两款共用新的原生几何外壳：双面厚度、圆润外瓣、带倒角的外沿、凹珠槽、分体旋钮、六角凹纹、外侧握持纹路与中央连接盘。珠子增加高光，模型按实际外壳范围适配显示大小。

外壳部件分为固定过渡区域、可翻转外瓣、分别随正背中央盘转动的内侧半壳。滚珠圈转动时壳体保持，翻瓣时相应壳体翻转；转一面中央盘时，另一面中央盘和半壳保持。两面之间有固定中轴接缝。相邻分组有切面，动画中不会只有珠子移动。该外壳是原创程序几何，并非厂商 CAD；没有增加实物机构认证结论。

录入、颜色编号、求解状态和保存格式保持兼容。壳体没有新增录入槽位，深度遮挡参与拾取，点旋钮、外壳和被遮挡的珠子不会误上色。空白珠使用共享灰模材质。教学提示线跳过不可填色的外壳表面。

网格与每个视图的最近一次外壳绘制批次均有缓存；颜色变化、滚珠圈转动可复用壳体批次，视角、大小、翻瓣或转盘姿态变化时重新计算。批次顶点使用紧凑数组，缓存不保留所有动画帧。
