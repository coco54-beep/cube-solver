# N 阶魔方

首页的 N 阶入口选择 6–14 阶。录入沿用普通魔方的简洁和高级界面，保留横竖屏布局、缩放、整面填充、取色、撤销、随机打乱和公式粘贴。求解结果使用同一动画播放界面。

## 求解实现

`CubeN` 保存真实阶数，克隆时也保留阶数。普通 2–5 阶走独立求解器，6–14 阶使用 `solver/solver_n.py`，不依赖打乱历史或录入模型的 home 标记。

1. 奇数阶按照六个固定中心归一化配色，提取角块及中棱为三阶核心。偶数阶使用真实角块和同奇偶的合成棱块构造三阶搜索问题。
2. 用现有三阶引擎还原核心。
3. 对每组翼棱，按位置、贴纸方向和颜色识别实际块。内层四循环修正该组奇偶，再通过共轭三循环排序。翼棱公式允许扰动尚未还原的中心。
4. 普通高阶中心直接按颜色选三循环，以每步能修正的颜色数优先考虑短公式。同色中心可以作为缓冲，减少为不可区分的中心分配标签所引入的多余移动。每组规划与原有标签排序方案比较，采用输出更短的方案。
5. 所有内部公式表示单层切片；输出转换为项目现有的宽层转动及其逆转组合，使逻辑模型和动画使用同一套记号。
6. 构造公式时检查其实际作用范围。完整结果在原始输入副本上重放，只有六面全部还原才返回成功；失败不输出部分步骤。

`solver/nxn_optimize.py` 将已验证的中心、翼棱公式按 24 种空间朝向重写，同时考虑正向和逆向三循环。准备动作搜索按播放器成本计权：外层转动算一步，单独内切片通常需展开为两个宽层动作。循环的三种起点按同一操作处理。最终反复合并同轴层动作，直到不能继续消除步骤。短公式表按需构建，最多保留八组，并支持取消。

中心颜色优化只用于普通高阶。粽子、镜面等带形状识别要求的模型仍使用原有块识别规划，并保留完整回放检查。

参考数学原理：Chris Hardwick 的 [各翼棱轨道奇偶独立性](https://www.speedcubing.com/chris/lemma2.html) 和 [中心轨道三循环及同色等价性](https://www.speedcubing.com/chris/lemma3.html)。代码使用本项目坐标模型实现，没有复制未提供软件许可的外部求解器。

## 当前限制

- 上限为 14 阶，与 `cube/cube_n.py` 和首页选项一致，不能解读为任意阶数支持。
- 采用构造式还原，不保证最短步数，较高阶可能产生较长解法。
- 6–14 阶已使用从贴纸重新录入的随机打乱及全层覆盖样本进行优化对比，详见 [2026-10-12 普通高阶优化报告](../reports/nxn-optimization/2026-10-12/report.md)。样本回放通过不等于所有状态的证明；安卓实机性能尚未验证。
- N 阶仅提供录入、求解和步骤回放，不提供教学演示；录入页隐藏教学入口。
- 中心轨道数量随阶数增长，首次构造共轭步骤的耗时会增长。后台求解提供分组进度及取消。
