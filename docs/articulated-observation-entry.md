# Mixup / Tangram 逐面观察录入

Mixup / Plus 正式入口现已按用户要求改为传统主模型内编辑，见 [传统 Mixup 录入](mixup-traditional-entry.md)。本文的 Mixup 框选／区域计数流程是被替换的旧设计，观察匹配器仍由新入口复用。

## 使用流程

Tangram 正式入口 `ArticulatedEntryScreen` 使用逐面录入。Mixup / Plus 已使用独立的传统模型录入页；下面保留其旧分区域流程供说明观察匹配器的用途。

### Tangram 普通版

- 只选颜色、逐面点涂，支持连续拖动涂色；不显示区域数量、形状卡片、方向与高低控件。
- 按普通异形录入页布局：左侧三维主模型，右侧顶部六个带颜色背景的编号；上一面／配色设置／下一面单列一行，下方是拧动、随机打乱、清空、撤销、还原、求解。手机竖屏沿用上下排列和滚动操作区。
- 填色直接在三维主模型当前面上完成，支持点涂和连续拖涂，不再显示独立平面画板。六面的观察区域和颜色统一附在三维表面；观察细分仍不代表物理块。
- 切面复用 `CubeOrientation` 和三维渲染器的整体翻转动画（0.55秒），与普通魔方按前、右、上、后、左、下连续走相邻面。已填颜色保持各自逻辑面归属，上边／右边参照随整体朝向更新。
- 动画期间禁用填色、切面及修改按钮；切页或应用暂停时取消动画并回到上一个完整观察面，不提交半截朝向。点击拾取缓存随取消／完成清理，避免用动画中的旧位置误涂。锁定视角及跟随控件使用公共组件，手动切面动画不改变任何魔方块位。
- 不再展示单独的三维观察预览或逐面确认按钮；涂满一面自动计入完成数。求解和拧动沿用原有跨面匹配，不跳到额外的形状录入页；匹配期间求解按钮可取消计算。
- 当前面与上边／右边参照合为一条简短提示，详细填色说明收进右上角帮助。清空前确认，配色仍进入统一配色设置页。
- 普通版和 Extreme 共用原有草稿、会话字段、三维主模型和翻面动画；普通版直接填色，Extreme 通过形状颜色卡片录入。
- 面板细分由现有型号所有候选切线叠加生成，以便直接记录变换后的颜色边界；这些涂色区域不代表新增的物理块。程序按面板内部观察点的颜色匹配完整实体，而非把细分格当成独立块。
- 六面共用固定拿法和参照。旧轮廓草稿迁移为相容的颜色观察；有矛盾的颜色不自动填入。

### Tangram Extreme

- 选块目录的“所有颜色”查询保留全部彩色面片，不再把空颜色筛选成空目录；点选灰色定位块和已录入面片均可打开形状配色卡片。
- 灰色未录入实体使用独立的拾取编号，点选后高亮所在位置；编号只用于界面定位，不作为物理块身份。
- 参照移棱录入页：在三维主模型上点位置，右侧出现带实际颜色的形状卡片；每页最多八张，同形同色但位置／方向不同的候选合成一张卡片。
- 点卡片直接录入；卡片使用与还原页相同的外壳、贴纸几何，显示真实实体形状和配色。圆箭头在屏幕射线对应的现有物理姿态之间切换；位置只有一个对应方向时明确提示。再次点击已选中的卡片保留当前方向。
- 卡片带颜色，因此不再额外显示调色板、形状确认、高低或区域数量。配色设置仍放在导航行，进入统一配色设置页。
- 点回已经录入的面片可重选卡片或方向；替换只移除本次选中的旧轮廓，不删除相邻的其他录入。目标轮廓已属于其他面片时拒绝覆盖；撤销恢复录入内容并清理过期候选，点模型可重新选择卡片。
- 通过三维整体翻转依次访问前、右、上、后、左、下六个相邻面；计算或动画期间禁用修改，切页取消临时状态。默认使用立体视角；3D 按钮可切换立体／正视，解锁后可拖动观察，视角变化不修改录入状态。
- 主模型与还原页共用 `ArticulatedView.piece_surfaces`，保留真实空间坐标、斜面法线、黑色外壳和贴纸厚度偏移，不把 Extreme 的六面压成平面外壳。点击按三维射线拾取，并使用旋转后的贴纸位置关联录入项。
- 未录入部分是灰色参考实体；选择的实体替换与其体积冲突的灰色占位，不用固定立方体外壳遮住已输入块。匹配完成后采用完整物理状态。尚未确定的灰色位置不是已经推断出的实物布局。
- 选择实体卡片同时保存所选实体的世界几何和观察深度，跨面匹配仍不保存来源块编号或打乱历史。与已录入实体冲突、覆盖已有面片的选择会保留原草稿并提示；合法的三维遮挡允许存在。
- 不需要额外点“本面录完”；匹配器仍要求每个实体都有观察约束、所有录入轮廓可见且跨面连接一致，搜索无法证明唯一时保留草稿，不应用任意候选。
- 深度由匹配器保留候选并联合其他面的观察判断；不同结构仍有歧义时不会自动应用。

### Mixup / Plus

1. 固定拿法，按前、右、后、左、上、下切换；每面常驻显示上边、右边参照。
2. 在正视图拖框选当前区域，再设置它分为多少块（1～12）。中心区、棱区都按眼前的分割计数，不要求知道它们原来的实体身份。直接点选也可建立一个小区域。
3. 选色后点面片所在位置。程序从本型号实体的候选姿态中筛选轮廓，卡片只显示形状，不显示内部块编号。同形的不同位置／方向用左右箭头切换。
4. 选择颜色、轮廓与方向后，点轮廓行的✓录入一张面片。高低默认自动匹配，出现歧义时可指定由外向内的候选层。
5. 区域数量齐后点数量行的✓确认区域。数量不齐、重复轮廓和多录不当作已完成。确认后的区域可再次点区域✓解除确认再编辑。
6. 当前面可见彩色面片录完后点“本面录完”；暂看不到或尚未录完可直接切下一面，不能把它标成已完整观察。
7. 主操作行✓匹配实体。拧动／求解按钮也先完成匹配；只有得到唯一的模型结构才应用。

删除按钮删除点选处的一张面片；空区域可删除，避免一次误拖框导致只能清空全部。撤销保存最近24次观察编辑。配色仍通过统一设置页面修改。

## 草稿与预览

- 草稿记录六向正投影轮廓、颜色、可选高低、区域数量和区域／面的完成状态，不记录用户猜测的内部编号。
- 未匹配前的三维画面标为“观察预览”，其中默认高低来自一个候选，仅供对照，不是已确定的实体状态。
- 匹配完成后显示完整实体；之后拧动返回录入页会重新生成对应六视图。未提交的观察草稿与已可播放的实体状态相互独立。
- 草稿和撤销状态接入应用原有会话保存。取消或切页不会让迟到的后台结果覆盖新输入。没有完成的草稿不被普通随机打乱覆盖。

## 匹配实现

`cube/articulated_observation.py` 根据现有型号的原始面片、有限姿态表和六个观察方向生成候选。二维轮廓按几何顶点匹配，保留同形轮廓背后的多个实体身份、朝向和高低。

后台用观察面片与物理块的精确覆盖约束关联跨面信息，拒绝同一块重复占位和实体相交。等价块按完整几何、角色、锚点与观察覆盖合并搜索对称性。可见性用面内多个采样点判断遮挡；它不是任意复杂遮挡下的精确多边形布尔运算。

- 每次轮廓筛选最多5秒；匹配最多8秒、10000个搜索节点，支持取消。
- 候选缓存只保留两个“型号／面／颜色”目录。
- 缺少实体观察信息、确定矛盾、多种非等价结构、达到计算限额分别返回不同状态。
- 不能用还原姿态或打乱记录填补未知块；达到限额时即使已找到一个候选，也不冒充已证明唯一。
- 结构匹配不等于证明物理可达或保证求解成功。深层手动状态仍受现有形状还原求解器限制，型号的有限姿态与机芯模型也仍需独立实物核对。
- 部分遮挡面片可从型号完整轮廓补选其延续部分；完全不可见的块可能无法唯一确定，需要补充其他观察。当前没有自由手绘切缝或照片自动轮廓识别。

## 完成范围

已接入正式入口、分区域计数、轮廓卡片、位置／方向、高低选择、颜色、跨面匹配、观察预览、撤销、取消、会话保存和拧动／求解入口。
