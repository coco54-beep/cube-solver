# Ghost Pyramid（鬼魔金字塔）

入口：首页 → 特殊异形 → 鬼魔金字塔 · Ghost Pyramid。

以乐方 Ghost Pyraminx 的14块斜转机制为目标：8个机制角、6个带方向的机制中心，单色外表，依靠形状和朝向区分。它与普通金字塔的独立角尖、棱块结构不同，也不是仅把普通金字塔改成银色。

## 当前模型的精度范围

四面体壳体分为14个刚性实体。先切错层面，把一半外壳展开到机制对齐状态，再切其余机制平面；收回错层后拼成完整金字塔。

目前是理想化几何实现：外壳倾角、偏心及60°收层角是模型参数，没有乐方厂商CAD或实物测量支持。不能把这些数值当作乐方实物的测量结果，切割交点和块比例仍须实物比对。公开照片能确认外观类别和结构，但不足以保证每块卡片与实物一一吻合。

## 录入、拧动和保存

- 按块形和朝向选择14个块，中心方向也保留。
- “错层对齐”打开转动状态；“收回错层”恢复外壳的收层角。
- 未对齐时禁止直接跨轴120°转动，并提示先对齐。
- 随机打乱从对齐状态生成；撤销、播放前后步、进度跳转和会话保存均保留错层角。
- 左右观察按钮按四个真实外壳面循环，不用内部六面斜转标号切换观察面。

## 求解

打开错层 → 求解虚拟斜转块位及角方向 → 处理6个中心的朝向 → 收回错层。

中心阶段复用相同斜转机制的预制32种合法中心朝向公式，每个方向均作为可见方向处理，不忽略镜面中心朝向。无需在手机临时建立完整带方向群表。返回前从输入状态逐步应用解法，要求所有实体块及收层角完成复原。
